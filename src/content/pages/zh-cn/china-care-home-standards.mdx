# 内地养老机构餐饮服务的标准体系

随着中国老龄化进程加速，民政部及相关部门已出台多项标准，规范养老机构的餐饮及照护食服务。了解这些标准，有助于照顾者在为家人选择养老机构时，评估其饮食安全能力。

---

## 民政部行业标准 MZ/T 032

### 标准概述

**MZ/T 032《养老机构服务质量基本规范》**（及相关修订版本）是民政部发布的养老机构服务质量核心标准，涵盖生活照料、饮食服务、医疗护理等多个方面。

### 饮食服务相关要求

MZ/T 032 对养老机构的饮食服务提出以下基本要求：

**膳食供应**
- 应根据老年人的身体状况、饮食禁忌及个人需求，提供**个性化膳食**
- 应提供普通饮食、软食、半流质、流质等**不同质地的食物**
- 每日三餐定时定量，两餐间隔不少于4小时
- 应有专职或兼职的营养专业人员参与膳食管理

**特殊饮食需求**
- 患有糖尿病、肾脏病、吞咽困难等特殊疾病的老年人，应提供**针对性的特殊饮食**
- 有吞咽障碍的老年人，应提供经过质地改良的食物，并记录相关护理措施

**进食辅助**
- 对无法自主进食的老年人，应提供专业的进食辅助服务
- 护理人员应接受进食辅助的基本培训

> **局限性说明：** MZ/T 032 提出了「质地改良食物」的方向性要求，但未对具体质地等级（如 IDDSI 分级）、测试方法及制备标准作出详细规定。IDDSI 框架在内地养老机构的采用仍处于初步阶段。

## GB/T 35796 养老机构服务基本要求

### 标准背景

**GB/T 35796《养老机构服务基本要求》**是由国家市场监督管理总局发布的推荐性国家标准，与 MZ/T 032 相辅相成，进一步细化了养老机构的服务质量要求。

### 与照护食相关的条款

GB/T 35796 在以下方面对餐饮服务作出规范：

| 条款方向 | 具体要求 |
|---------|---------|
| 膳食质量 | 食物卫生安全，符合国家食品安全标准 |
| 个性化服务 | 尊重老年人的饮食习惯及文化背景 |
| 特殊饮食 | 为有医学需求的老年人提供治疗性膳食 |
| 进食环境 | 提供安全、舒适的进餐环境及辅助器具 |
| 记录管理 | 记录老年人的饮食状况及进食量 |

## 老年友善医疗机构标准

### 政策背景

国家卫生健康委员会推进「老年友善医疗机构」建设，要求医疗机构在以下方面符合老年友善标准：

- 吞咽障碍的早期筛查与评估
- 营养风险筛查（使用 MNA-SF 等工具）
- 多学科团队参与老年综合评估（CGA）
- 提供符合老年患者需求的膳食选择

**吞咽困难的院内评估要求：**
- 三级医院应配备言语治疗师进行专业吞咽评估
- 对有误吸高风险的患者，应进行器械评估（如电视透视吞咽检查 VFSS）
- 出院时应提供饮食建议及照护食指引

## 照护食在内地养老机构的现状

### 执行差距

尽管相关标准已明确要求提供质地改良食物，内地养老机构在照护食方面仍存在明显差距：

| 挑战 | 说明 |
|------|------|
| 标准细化不足 | 现行标准未采用 IDDSI 分级体系，质地描述（「软食」「半流质」）缺乏统一定义 |
| 专业人才短缺 | 养老机构中持证言语治疗师极少，多由护理员兼职处理进食辅助 |
| 器具与设施 | 制备照护食所需的破壁机、细目筛等器具配置参差不齐 |
| 成本压力 | 个性化照护食的制备成本高于普通膳食，部分机构缺乏动力落实 |
| 家属认知 | 家属及老年人对改良质地饮食的接受度有待提高 |

### 较好实践的养老机构特征

选择养老机构时，可参考以下指标评估其照护食服务水平：

- 配有专职或兼职营养师，定期评估入住老人的营养状况
- 有言语治疗师或经过吞咽评估培训的护士定期驻诊
- 厨房配备破壁机、细目筛等制备照护食的设备
- 能提供至少三种质地选择（软食、糊状食物、流质）
- 护理记录中有饮食质地及进食量的追踪记录

## IDDSI 框架在内地的推广现状

国际吞咽障碍饮食标准化倡议（IDDSI）自2017年正式发布后，已在香港、台湾、新加坡及多个西方国家得到广泛采用。内地方面：

- 部分三甲医院的言语治疗科已引入 IDDSI 分级用于临床评估
- 中国康复医学会吞咽障碍康复专委会正在推进 IDDSI 的本土化工作
- 养老机构层面的 IDDSI 应用仍属少数，主要集中在一线城市的高端机构

> **照顾者建议：** 若家人需入住养老机构，可直接询问机构是否使用 IDDSI 分级体系，这是评估其照护食专业水平的有效指标。

## 如何评估养老机构的照护食能力

选择养老机构时，建议向机构提出以下问题：

1. 是否有专业的吞咽评估服务（院内言语治疗师或定期外聘）？
2. 厨房是否能提供糊状（Level 4）及细碎湿润（Level 5）食物？
3. 是否提供增稠液体服务？使用什么增稠剂，如何配制？
4. 护理员是否接受过进食辅助专业培训？
5. 如果入住后需要改变饮食质地，流程是什么？

## 常见问题

**Q：内地养老机构是否有义务提供改良质地食物？**

A：根据 MZ/T 032 及 GB/T 35796，养老机构有义务为有特殊饮食需求的老年人（包括吞咽困难患者）提供个性化膳食，包括质地改良食物。但由于标准细化程度不足，执行情况因机构而异。建议在签订入住合约前，明确将饮食质地要求列入服务协议。

**Q：如何投诉未能提供适当照护食的养老机构？**

A：可向当地民政局或养老服务监督热线（通常为12345政务服务热线）投诉。同时，可通过民政部全国养老机构管理系统查询机构的评级及投诉记录。

**Q：私立高端养老机构是否有更好的照护食服务？**

A：一般而言，高端私立养老机构在照护食方面的投入较多，部分已引入 IDDSI 分级。但价格并不等于质量——建议实地参观并询问具体服务细节，而非仅凭收费标准判断。
