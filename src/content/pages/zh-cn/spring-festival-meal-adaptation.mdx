# 春节家庭年夜饭：让吞咽障碍家人安全参与团圆饭

年夜饭是中华文化中最重要的家庭仪式。一桌丰盛的菜肴、一家人围坐在一起——这个画面在中国人心中承载着团圆、归属和对新年的期盼。当家中有吞咽障碍的老人时，如何让他/她安全参与这顿年夜饭，同时不让安全考虑成为节日气氛的阴影，是家庭照护者需要提前思考和准备的。

---

## 春节饮食的高风险食物识别

年夜饭的传统菜肴中，有相当一部分对吞咽障碍患者来说存在高风险：

### 高风险食物（应谨慎或避免）

| 食物 | 风险 | 建议 |
|-----|-----|-----|
| 年糕 | 高度黏性，极易粘附咽部 | **避免**，改用其他软滑替代品 |
| 糯米糍/汤圆 | 同上，黏性高 | **避免**，改用豆花/嫩豆腐 |
| 花生/坚果 | 硬、易碎成不规则颗粒 | **避免**，改用磨细的花生酱 |
| 带壳虾/蟹 | 操作复杂，壳碎片危险 | 去壳后评估虾肉质地 |
| 腊肠/腊肉 | 质地干硬、含盐量高 | **避免** |
| 鱼（有刺） | 鱼刺危险 | 选择少刺鱼种，细心去刺 |
| 整颗葡萄/荔枝/龙眼 | 圆形、光滑，误吸风险 | 去皮切半或压泥 |
| 油炸食品（炸鸡腿等） | 外皮干脆易碎，内部可能有混合质地 | **避免**，改用炖煮方式 |

了解[吞咽障碍的发生机制](/zh-cn/dysphagia-mechanism)有助于理解为何黏性食物和硬质食物特别危险。

## 年夜饭的适应方案

### 原则：保留仪式感，改造不安全的细节

不必将年夜饭变成"医疗餐"。通过精心的提前准备，绝大多数节日氛围可以保留：

**精心摆盘**：将改造后的食物盛放在与家人相同风格的餐具中，不要用"医疗碗"区别对待

**共同进食节奏**：吞咽障碍家人使用改造后的食物，在同一时间与家人共同开始进食，共享同一桌的节日气氛

**敬酒替代方案**：以增稠的茶或果汁（调至适当IDDSI等级）参与碰杯仪式，保留节日仪式感

### 可改造的传统年夜饭菜肴

**白切鸡 → 鸡肉泥蒸蛋**
- 将无骨无皮鸡肉蒸熟后打成细腻鸡肉泥
- 与鸡蛋液和高汤混合蒸制
- 淋上姜葱豉油（传统白切鸡的灵魂调味）
- 可达IDDSI 4-5级

**清蒸鱼 → 鱼泥蒸蛋**
- 选用鳕鱼或龙利鱼（少刺，细腻去刺后打泥）
- 与鸡蛋液蒸制，淋上原鱼汁和葱姜
- 保留清蒸鱼的香气，呈现节日感

**红烧肉 → 酱汁猪肉糊**
- 五花肉以酱油、八角长时间炖煮（2小时以上）至软烂
- 去除外皮（皮质地不均匀），将肉质极软的部分连同酱汁一起打糊
- 独特的酱香可以让患者感受到节日气氛

**汤类（鱼头豆腐汤、冬瓜蟹肉汤等）**
- 取汤液按IDDSI处方加入适量增稠剂
- 汤料中的豆腐和极软蔬菜（冬瓜等）可单独给予
- 汤的香气和味道是节日体验的重要组成部分

**年糕 → 南瓜芋头糕（软滑版）**
- 南瓜和芋头蒸熟后压泥，加入少量糯米粉（不超过10%，降低黏性）
- 制成软滑质地（IDDSI 5级），刻意避开年糕的高黏性
- 保留节日"糕"字的吉祥寓意

## 年夜饭的进食安全管理

### 饭前准备

- **确认IDDSI处方**：在年夜饭当天早上再次确认患者的IDDSI等级（避免节日特殊情况下的信息遗漏）
- **增稠饮料预备**：提前配制足够量的增稠饮料，并进行IDDSI质地测试
- **座位安排**：将吞咽障碍家人安排在便于照护者协助的位置，同时能参与整桌的视线互动

### 进食过程中

- **指定协助者**：年夜饭热闹，应提前确认由谁负责照看吞咽障碍家人的进食
- **控制节奏**：热闹的气氛可能导致患者进食节奏加快，协助者需温和提醒
- **减少催促**：不要因为要"赶快一起吃"而催促患者加快进食
- **处理拒绝**：若患者坚持要吃高风险食物（如年糕），照护者可以先认可其想法，再提供改造替代品

### 进食后

- 保持坐位至少30分钟
- 进行口腔清洁
- 节日后恢复正常进食监测记录

## 照护者在节日中的自我关顾

年节照护往往是年度中最消耗照护者体力和情绪的时段：家庭聚会的欢乐气氛与照护工作的持续紧张同时存在，令照护者在"应该快乐"和"其实很累"之间拉扯。

几点建议：

- 提前分工，让其他家庭成员承担年夜饭中的部分照护工作
- 明确告知其他家庭成员患者的IDDSI要求，避免亲戚好意给患者危险食物
- 允许自己在节日中也有情绪，不必强迫自己永远乐观
- 节后如感到极度疲惫，考虑[喘息服务安排](/zh-cn/respite-care-for-caregivers)
