# 为什么吞咽困难长者需要更多蛋白质？

蛋白质是维持肌肉量、免疫功能及伤口愈合的基础营养素。然而，吞咽困难（Dysphagia）长者面临双重挑战：一方面，年龄本身已使蛋白质需求增加；另一方面，质感改良饮食令高蛋白食物（肉类、坚果、豆类）的摄取受到限制。

长期蛋白质摄取不足，会导致以下后果：

- **肌少症（Sarcopenia）**：肌肉量及力量下降，增加跌倒及功能依赖风险
- **免疫力削弱**：感染及吸入性肺炎风险上升
- **伤口愈合迟缓**：手术后、压疮及骨折康复受阻
- **疲劳及认知功能下降**：影响日常活动及生活质素

---

## 长者的蛋白质摄取目标

一般成年人的蛋白质建议摄取量为每公斤体重每日 0.8g。但长者及有疾病的患者，建议量显著提高：

| 情况 | 蛋白质建议摄取量（每公斤体重/日）|
|------|-------------------------------|
| 一般健康长者（65 岁以上）| 1.0–1.2g |
| 急性病或手术后恢复期 | 1.2–1.5g |
| 有压疮或慢性伤口 | 1.5–2.0g |
| 确诊或高风险肌少症 | 1.2–1.5g |
| 严重营养不良 | 1.5g 或以上（需营养师评估）|

**实例：** 一位体重 52kg 的长者，一般目标为每日 52–62g 蛋白质。有压疮时，目标可高达 78–104g。

## 香港常见质感改良食物的蛋白质含量

以下食物均可在不调整 IDDSI 等级的前提下提供蛋白质：

| 食物（已按质感改良处理）| 份量 | 蛋白质含量 |
|----------------------|------|-----------|
| 蒸水蛋（全蛋）| 1 只（约 60g）| 约 8g |
| 嫩豆腐（蒸或直接食用，Level 4）| 100g | 约 5–6g |
| 蒸去骨鱼柳（草鱼、马头鱼）| 100g | 约 18–20g |
| 猪绞肉蒸肉饼（Level 5 细碎）| 100g | 约 15–17g |
| 鸡绞肉蒸（Level 5）| 100g | 约 18g |
| 全脂奶粉（加入食物或粥底）| 2 汤匙（约 30g）| 约 5–7g |
| 原味豆浆（需增稠至指定等级）| 240ml | 约 7–9g |
| 蒸蛋豆腐（含豆浆）| 100g | 约 6–7g |

## 如何在质感改良饮食中提升蛋白质摄取

### 策略一：选用天然高蛋白软质食材

广东菜中以下食材天然质感柔软，同时含丰富蛋白质：

- **鸡蛋**：蒸水蛋、炖蛋、加入粥底——多用途且 IDDSI Level 4 兼容
- **鱼类**：蒸去骨白鱼柳、草鱼蒸片（务必彻底去骨）
- **猪/鸡绞肉**：蒸肉饼、加入粥底；可达 IDDSI Level 5
- **嫩豆腐**：天然 Level 4 质感，蛋白质、钙质兼备
- **无糖豆浆**：液态蛋白质来源，需按指定 IDDSI 等级增稠

### 策略二：加入蛋白质强化剂

在不改变食物 IDDSI 等级的前提下，以下添加物可提升蛋白质含量：

**全脂奶粉：**
- 每 2 汤匙可提供约 5–7g 蛋白质
- 加入粥底、炖蛋或蔬菜糊中
- 同时提升能量及钙质摄取

**无味蛋白粉（乳清或豌豆蛋白）：**
- 选择无甜味、可溶于液体的款式
- 加入糊状食物或增稠饮品
- 每份（约 20–25g）可额外提供 15–20g 蛋白质

**蛋白质口服补充剂（Protein Module）：**
- 医疗级蛋白质模组，香港药房或医疗用品店可购得
- 在已有均衡饮食的基础上补充蛋白质
- 应在医生或营养师建议下使用

### 策略三：采用少食多餐策略

吞咽困难长者每餐进食量较少，难以在三餐中达到蛋白质目标。建议：

- 每日分 5–6 次进食，每次均确保含有蛋白质
- 避免以白粥或纯淀粉食物作为主食，应加入蛋、鱼、肉或豆腐
- 午后的加餐可提供蒸水蛋或增稠豆浆

## 常见蛋白质来源的制备方法（香港家庭）

### 蒸水蛋（IDDSI Level 4）

1. 全蛋 2 只打散，加入等量或 1.5 倍体积的清鸡汤（去油）
2. 过筛去除气泡
3. 中小火蒸 8–10 分钟至刚刚凝固
4. 上桌前可加少量姜汁豉油提味（注意液体稠度）

> **蛋白质含量**：约 14–16g（2 只蛋加鸡汤）

### 蒸鱼柳（IDDSI Level 5–6）

1. 选用刺少的白鱼（马头鱼、草鱼）
2. 彻底去骨（至少两次确认），切成 1cm 以下小块
3. 加入少量姜葱，以中火蒸 6–8 分钟
4. 蒸熟后再次确认质感，叉子压力测试通过后上桌

> **重要**：鱼骨是吞咽困难患者的高风险异物，每次均需彻底去骨。

## 微量营养素：蛋白质以外不可忽视

在提升蛋白质摄取的同时，以下微量营养素亦容易在质感改良饮食中出现不足：

| 微量营养素 | 功能 | 香港照护食来源 |
|----------|------|--------------|
| 维他命 B12 | 神经功能及红血球 | 蒸鱼、炖蛋、奶制品 |
| 铁质 | 预防贫血 | 猪绞肉蒸饼、肝酱（过筛）|
| 锌 | 免疫力及伤口愈合 | 绞肉、嫩豆腐 |
| 钙质 | 骨骼及肌肉收缩 | 奶粉、嫩豆腐、芝麻糊（增稠）|

## 何时需要转介营养师

以下情况应向主诊医生或言语治疗师要求转介至**注册营养师（Registered Dietitian）**：

- 体重在 3 个月内下降超过 5%
- 患者食量持续不足，摄取量明显低于需求
- 患有糖尿病、慢性肾病等需特殊饮食管理的疾病
- 照顾者不确定如何在 IDDSI 饮食中达到蛋白质目标
- 考虑使用鼻胃管（NG tube）或肠道管饲

### 香港转介途径

|------|------|
| 公立医院门诊营养科 | 由主诊医生或言语治疗师转介；等候时间因联网而异 |

| 私家诊所营养师 | 自费；香港营养师学会（HKDA）设有名册 |

## 常见问题

**Q：吞咽困难长者可以吃蛋白棒或健身蛋白补充剂吗？**

A：大部分市售蛋白棒质感坚硬（IDDSI Level 7 或以上），不适合吞咽困难患者。健身用蛋白粉通常含大量人工甜味剂，且非针对长者设计。如需使用蛋白质补充剂，应选择无甜味、可完全溶解的医疗级或食品级蛋白粉，并在营养师建议下使用。

**Q：增加蛋白质摄取会对肾脏造成负担吗？**

A：肾功能正常的长者可安全摄取 1.0–1.5g/kg 的蛋白质。患有慢性肾病（CKD）的患者需要限制蛋白质摄取，蛋白质目标应由肾科医生及营养师共同制定。切勿自行大幅增加蛋白质而不先咨询医疗团队。

**Q：豆腐是否足够替代肉类的蛋白质？**

A：豆腐是良好的植物性蛋白质来源，但每 100g 嫩豆腐仅含约 5–6g 蛋白质，相较于肉类（每 100g 约 15–20g）密度较低。若以豆腐作为主要蛋白质来源，需要食用较大份量，或配合奶粉、蛋白粉等强化策略才能达到每日目标。

**Q：蒸水蛋可以每日食用吗？**

A：可以。蛋类不需要严格限制（除非医生因心脏病等原因建议）。健康长者每日 1–2 只鸡蛋是合理的。鸡蛋提供优质蛋白质、维他命 D、B12 及胆碱，是质感改良饮食中非常实用的食材。

**Q：市场上有哪些香港品牌的口服蛋白质补充剂？**

A：香港药房（万宁、屈臣氏）及医疗用品店可找到多种口服补充剂。选择时应注意：是否需要增稠（液态补充品通常为 IDDSI Level 0）、糖分及人工甜味剂含量，以及是否需要医生或营养师处方。具体产品选择应咨询主诊医生或营养师。
