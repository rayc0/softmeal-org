# 什么是长期护理保险？

**长期护理保险（长护险，LTCI）**是中国正在建设的第六项社会保险，专门用于支持因年老、疾病或残障导致失能的人群的长期照护费用。2016年起，国家医保局在部分城市开展长护险试点；2020年试点城市扩展至49个，目前仍在持续探索建立全国统一制度。

对于吞咽障碍患者而言，长护险是获得专业评估和照护费用支持的重要渠道——但各试点城市的保障范围差异很大，照护者需要了解所在城市的具体政策。

## 49个试点城市中的重点城市

以下10个试点城市在长护险覆盖范围和吞咽障碍相关保障方面具有代表性：

| 城市 | 主要特点 |
|------|---------|
| **上海** | 全国覆盖最广，保障项目最完善，涵盖多项专业照护服务 |
| **成都** | 居家照护和机构照护均有较完善的报销体系 |
| **苏州** | 较早试点，有成熟的评估体系和定点机构网络 |
| **广州** | 大湾区核心城市，已有独立的长护险条例 |
| **南通** | 居家护理报销比例较高 |
| **宁波** | 保障范围较广，包括部分康复服务 |
| **北京** | 2021年启动试点，保障范围仍在扩展中 |
| **重庆** | 四直辖市中试点较完善 |
| **青岛** | 老牌试点城市，有完整的分级评估制度 |
| **深圳** | 大湾区另一核心城市，与广州制度有所不同 |

## 吞咽障碍患者可获得的保障

长护险对吞咽障碍患者的保障，因城市不同而差异较大，以下为各城市可能覆盖的项目：

### 基础照护（大多数试点城市覆盖）
- 日常生活照料（协助进食、口腔护理）
- 居家护理人员的部分费用

### 专业服务（部分城市覆盖）
- **吞咽评估**：由言语治疗师或康复医师进行的专业吞咽评估
- **吞咽康复训练**：定期由言语治疗师提供的吞咽训练
- **营养评估**：由营养师进行的营养状况评估

### 辅助用品/食品（少数城市覆盖或试行中）
- 增稠剂费用（部分城市纳入辅助器具补贴）
- 特殊医学用途配方食品（FSMP）
- 口腔护理用品

## 如何申请长护险？

一般申请流程（各城市略有不同）：

**第一步：确认参保资格**
- 通常需为当地基本医疗保险参保人
- 一般要求失能状态持续6个月以上
- 年龄要求：大多数城市要求60岁以上，部分城市无年龄限制

**第二步：提出申请**
- 向参保地医保局或指定经办机构提出申请
- 提交医院诊断证明、失能状态证明等材料

**第三步：失能评估**
- 由医保局委托的专业评估机构进行上门评估
- 评估通常使用**Barthel指数**或类似量表
- 评估结果分为重度、中度、轻度失能（各城市分级不同）

**第四步：确定待遇**
- 根据失能等级，获得相应的护理费用补贴
- 可选择居家照护或入住定点养老机构

---

## 吞咽障碍患者的申请建议

1. **在医院就诊时请言语治疗师出具评估报告**，详细记录吞咽障碍的严重程度和日常照护需求
2. **申请失能评估时，主动说明吞咽障碍对日常生活的影响**，包括进食所需协助时间和特殊饮食需求
3. **了解所在城市的定点服务机构**，部分可提供言语治疗上门服务的机构可能在长护险定点名单内
4. **保留所有与吞咽障碍相关的医疗文件**（评估报告、诊断证明、住院记录），作为申请支持材料

## 全国推广展望

2024年，国家医保局发布了关于推进长护险制度建设的相关文件，明确了向全国推广的方向。预计在"十五五"规划期间（2026至2030年），长护险将逐步形成全国统一的制度框架。

**对吞咽障碍照护的影响：**全国制度统一后，吞咽评估和专业照护的保障范围有望扩大，吞咽障碍患者获得专业支持的可及性将显著提升。照护者现在了解和申请长护险，不仅能获得当前保障，也有助于在制度扩展时第一时间享受新增权益。
