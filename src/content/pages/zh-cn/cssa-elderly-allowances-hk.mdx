# 前言：照顾费用的现实压力

吞咽困难（吞咽障碍）的日常照顾涉及大量额外开支——增稠剂、特制食品、私家言语治疗费用，以及因照顾责任减少的工作收入。香港社会福利制度设有多项计划，为有需要的患者及家庭提供财务支援。本文专门整理**综合社会保障援助（综援／CSSA）**及**长者生活津贴（OALA）**在吞咽困难护理场景下的适用情况，并列出实际申请步骤。

---

## 一、综合社会保障援助（CSSA）

### 什么是综援？

综援（Comprehensive Social Security Assistance，CSSA）是社会福利署（SWD）的援助计划，向无法自给自足的香港居民提供现金援助，维持基本生活需要。

### 适用于吞咽困难患者的情况

以下情况的患者或照顾者可考虑申请：

- 吞咽困难导致严重身体残疾，无法从事任何有薪工作
- 全职照顾吞咽困难家人而放弃工作的照顾者（以「照顾残疾成员」类别申请）
- 长期病患入息不足，需补贴照顾开支

### 综援的特别津贴与吞咽护理

获批综援的个案，按实际需要可申请以下**特别津贴（Special Grants）**：

| 特别津贴类别 | 适用情况 |
|---|---|
| 特别饮食津贴 | 因病需要特定饮食（如低糖、低盐、特殊质感） |
| 护理费用补贴 | 需要购买护理用品（包括增稠剂、吸管辅助器） |
| 医疗费用补贴 | 需定期复诊或接受言语治疗 |
| 交通费补贴 | 需定期前往医院或治疗中心 |

**实际金额**：特别津贴金额由社工按个案实际情况评估，并非固定金额。

### 申请方式

1. 前往所属地区的**社会福利署综合家庭服务中心（IFSC）**
2. 或致电社会福利署热线：**2343 2255**
3. 准备文件：香港身份证、住址证明、医生诊断证明（说明吞咽困难病情及护理需要）、入息及资产证明
4. 社工会进行入息及资产审查，并安排家访评估

**申请资料**：www.swd.gov.hk > 社会保障 > 综合社会保障援助计划

## 二、长者生活津贴（OALA）

### 计划概览

长者生活津贴（Old Age Living Allowance，OALA）为**65岁或以上**、通过入息及资产审查的香港长者提供每月现金援助。

**2026年月额（参考）**：
- **高额长者生活津贴**：每月 HK$4,060（65岁或以上，严格入息审查）
- **普通长者生活津贴**：每月 HK$2,715（65岁或以上，宽松入息审查）

长者生活津贴**毋须指定用途**，可由长者自行决定如何运用，包括用于购买吞咽困难相关护理物资。

### 与伤残津贴的区别

| 计划 | 年龄要求 | 入息审查 | 伤残要求 | 月额（2026年） |
|---|---|---|---|---|
| 长者生活津贴 | 65岁或以上 | 有 | 无 | HK$2,715 – HK$4,060 |
| 伤残津贴（普通） | 无 | 无 | 有 | HK$1,990 |
| 伤残津贴（高额） | 无 | 无 | 有（需长期护理） | HK$3,975 |

**注意**：伤残津贴及长者生活津贴可同时申请，但须分别符合各自的资格条件，且两者合计金额会影响综援的计算。

### OALA 申请方式

1. 网上申请：www.swd.gov.hk > 社会保障 > 长者生活津贴
2. 亲临就近的**社会保障办事处**提交申请
3. 热线：**2343 2255**
4. 文件：香港永久居民身份证、入息及资产声明

## 三、高龄津贴（生果金）

年满**70岁**的香港居民，无论入息多少，均可申请**高龄津贴（俗称「生果金」）**。

**2026年月额（参考）**：HK$1,485

虽然金额较低，但毋须入息审查，申请手续简便，适合所有符合资格的长者作为基础补贴。

**申请**：www.swd.gov.hk > 社会保障 > 高龄津贴

## 四、与吞咽护理直接相关的申请技巧

### 医生信的重要性

申请综援或伤残津贴时，医生诊断信应清楚说明：
- 吞咽困难的诊断（如：脑中风后遗症导致严重吞咽障碍）
- 需要特殊质感饮食（如：IDDSI 第3-4级流质饮食）
- 需要增稠剂及护理辅助用品
- 日常生活自理能力的限制程度

### 由医务社工协助申请

公立医院的**医务社工（MSW）**熟悉各项福利计划的申请流程，可：
- 协助评估符合哪些计划的资格
- 协助准备申请文件
- 转介至社署跟进

住院期间主动要求与医务社工会面，是获取最多支援的最有效途径。

### 申请后的持续支援

获批综援后，个案社工会定期覆核个案（一般每12至24个月），可于覆核时更新吞咽困难的护理需要，申请调整特别津贴。

## 五、常见问题

**Q：外佣（外籍家庭佣工）可以协助记录照顾需要以支持申请吗？**
A：可以。外佣的照顾记录（如每餐食物质感、摄食量）有助社工评估护理需要，但外佣本身不是申请人。

**Q：吞咽困难患者住院期间，其家人能否申请紧急综援？**
A：可以申请「紧急援助」，适用于突发财务困难情况，审批较一般申请快，可向医务社工或就近IFSC查询。

**Q：申请被拒可否上诉？**
A：可以。申请人有权于收到拒绝通知后一个月内，向社会保障上诉委员会提出上诉，费用全免。
