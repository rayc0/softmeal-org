# 养老机构 IDDSI 全面推行指引：从计划到落实的逐步路径

国际吞咽障碍饮食标准倡议（IDDSI）是全球公认的食物质地和液体浓稠度分级体系，为吞咽障碍患者的安全进食提供了统一、可量化的标准语言。在中国大陆的养老机构中，随着长护险制度的推进和民政部养老服务质量标准的不断完善，IDDSI 的推行已成为提升机构照护质量的重要举措。本文提供一套系统化的推行路径，供机构管理者和护理团队参考。

---

## 推行前的准备工作

### 现状评估

在正式启动前，机构应完成以下现状评估：

1. **居民吞咽状况普查**：
   - 统计现有居民中已确诊吞咽障碍的比例
   - 识别有吞咽障碍症状但尚未正式评估的高风险居民（参考[吞咽障碍发生机制](/zh-cn/dysphagia-mechanism)了解高风险特征）
   - 记录目前各居民所使用的饮食质地描述方式（如"软饭"、"糊饭"等非标准化描述）

2. **厨房能力评估**：
   - 现有设备是否支持IDDSI不同等级食物的制备（搅拌机、过滤设备等）
   - 厨师和厨房员工的质地改造技能水平
   - 供应商提供的预制食品是否符合IDDSI标准

3. **人员能力评估**：
   - 护理员对吞咽障碍认知程度
   - 机构内是否有言语治疗师（ST）资源（驻场或兼职）

### 建立推行小组

建议由以下成员组成机构级IDDSI推行工作组：

- **项目负责人**：院长或护理部主任
- **临床顾问**：言语治疗师（驻场或外聘）
- **营养顾问**：营养师
- **培训协调员**：护士长或高级护理员
- **厨房代表**：厨师长或餐饮主管

根据国际吞咽障碍饮食标准（IDDSI）框架的推行建议，多学科协作是成功推行的核心（[IDDSI Framework](https://www.iddsi.org/framework)）。

## 分阶段推行路径

### 第一阶段：知识建立（第1-2个月）

**目标**：确保关键人员理解IDDSI框架的基本原理

- 完成全体护理员的基础IDDSI培训（8级分类、颜色编码、每级对应的食物质地特征）
- 厨师长和厨房核心员工接受质地测试培训（流量测试、叉子试验、汤匙倾斜试验、压力试验）
- 引进IDDSI测试工具（5ml注射器用于流量测试、叉子、量杯等）

### 第二阶段：标准建立（第3-4个月）

**目标**：建立机构IDDSI标准食谱和制备规程

- 由营养师和厨师长共同制定各IDDSI等级的标准食谱（至少涵盖早餐、午餐、晚餐）
- 对每份标准食谱进行IDDSI质地测试验证并文档化
- 建立各级食物的视觉参考标准（照片档案，便于日常质量核对）
- 设计标准化的增稠液体配制流程（各增稠剂品牌的用量表）

### 第三阶段：居民评估与分配（第5-6个月）

**目标**：为每位居民分配个体化IDDSI等级处方

- 由言语治疗师（ST）为所有确诊或疑似吞咽障碍的居民进行正式评估
- 为每位居民开具IDDSI等级处方（固体食物等级 + 液体浓稠度等级，两者独立）
- 在居民护理档案、餐卡和进食记录表上清晰标注IDDSI等级
- 建立护理交接班中IDDSI等级核查的标准流程

根据美国言语-语言-听力协会（ASHA）的成人吞咽障碍临床指引，IDDSI等级处方必须由具备资质的ST开具，不得由护理员或家属自行决定（[ASHA Adult Dysphagia](https://www.asha.org/practice-portal/clinical-topics/adult-dysphagia/)）。

### 第四阶段：全面运营（第7个月起）

**目标**：IDDSI分级系统成为机构日常运营标准

- 所有新入住居民在入住后72小时内完成吞咽初筛，高风险者转ST评估
- 每餐出餐前由厨房主管进行质地目视核查
- 每月进行IDDSI合规性审计（参考[吞咽安全审计清单](/zh-cn/audit-checklist-care-home)）
- 定期（每6个月）重新评估并更新居民的IDDSI等级处方

## 常见推行障碍与对策

| 障碍 | 解决对策 |
|-----|---------|
| 厨师担心工作量增加 | 提供标准化预混配方，优化厨房流程，减少重复测试 |
| 护理员记不住8个等级 | 制作彩色速查卡贴于护理站和餐厅 |
| 居民拒绝改变饮食习惯 | 重视食物外观和口味，让家属参与适应过程 |
| 家属不理解为何不能吃"正常食物" | 组织家属说明会，结合吞咽安全教育 |
| ST资源不足 | 建立与附近三甲医院言语治疗科的转诊合作机制 |
| 供应商食品无IDDSI认证 | 采购前要求供应商提供IDDSI测试报告或自行测试验证 |

## 与大陆政策框架的对接

### 长护险服务标准对接

在已开展长护险试点的城市（上海、成都、广州等），养老机构的照护质量评估中逐步纳入吞咽障碍管理指标。IDDSI系统的实施有助于机构：

- 在长护险质量评估中获得更高评级
- 为吞咽障碍相关的特殊饮食服务申请额外补贴提供文档依据
- 降低吸入性肺炎事故率，减少相关医疗费用和法律风险

### 民政部养老机构服务质量标准

依据《养老机构服务质量基本规范》（GB/T 35796），养老机构须为有特殊饮食需求的老年人提供符合要求的饮食服务。IDDSI系统可作为该标准的具体落实工具。

---

## 推行成本与资源估算

机构在规划推行预算时可参考以下成本项目：

- **培训成本**：专业ST外聘培训费用，建议每年至少2次全员培训
- **设备成本**：IDDSI测试工具（低成本），可能需要采购额外搅拌设备
- **食材成本变化**：质地改造食品制备成本可能增加10-20%，但可通过减少食物浪费部分抵消
- **文档系统**：如已有护理管理系统，可添加IDDSI模块；若无，可先使用纸质护理卡
