# 口服营养补充品选择指引：吞咽障碍患者如何选对补充品

当吞咽障碍患者无法通过日常饮食摄入足够的热量和营养素时，口服营养补充品（Oral Nutritional Supplements，ONS）是最常见的介入手段。然而，市面上产品种类繁多，不同产品在质地、营养成分、适用疾病状态和口味方面差异显著。选择不当可能导致：患者拒绝服用、质地不符合吞咽安全要求，或营养成分不匹配患者的医疗状况。

---

## 口服营养补充品的分类

### 按剂型分类

**液体型（即饮型）**
- 最常见形式，如安素（Ensure）、佳维体等
- IDDSI质地等级通常为0级（稀薄液体）至1级（极细流体），**直接饮用的稀薄液体对大多数吞咽障碍患者不安全**，需加增稠剂调整
- 优点：口感好、营养密度高、方便携带
- 缺点：需增稠处理，加增稠剂后口味可能改变

**半固体型（布丁型/凝胶型）**
- 专为吞咽障碍设计，质地通常为IDDSI 3-4级
- 无需增稠处理，可直接使用
- 在大陆市场相对少见，部分进口品牌可在电商平台购买
- 优点：安全便捷，无需额外处理；缺点：价格较高

**粉末型**
- 需按比例冲泡，可根据需要调整浓度
- 冲泡后质地取决于浓度和是否添加增稠剂
- 部分产品可拌入食物中（如全脂奶粉、蛋白粉）

**浓缩型（高热量密度）**
- 每100ml提供约150-200kcal（普通液体型约100kcal/100ml）
- 适合进食量极少的患者
- 常见于老年医学科、姑息治疗场景

## 大陆市场常见产品比较

### 通用型（适合大多数老年患者）

**安素（Abbott Ensure）**
- 热量密度：约100kcal/100ml
- 蛋白质：约3.5g/100ml
- 特点：无乳糖配方，口味选项多（香草、巧克力等）
- 适用：一般营养补充，无特殊疾病限制的老年患者
- **吞咽安全注意**：液体状态为0级稀薄液体，必须根据ST处方加入增稠剂

**佳维体（Fresubin）**
- 热量密度：约100kcal/100ml
- 蛋白质：约3.8g/100ml
- 特点：含纤维配方可改善便秘
- 适用：长期使用ONS、存在便秘问题的患者

**康全力（Nutrison）**
- 热量密度：约100kcal/100ml
- 特点：有管饲专用版和口服版，需区分
- 注意：某些管饲配方不适合直接口服，需确认产品标签

### 疾病专用型

**糖尿病适用（低血糖指数配方）**
- 特点：低碳水化合物、高单不饱和脂肪酸，使用慢消化碳水化合物
- 适用：2型糖尿病合并吞咽障碍患者
- 大陆常见品牌：安素糖尿病配方、雅培佳比（Glucerna）

**肾病适用（低磷低钾配方）**
- 蛋白质含量经过精确控制，磷、钾含量低
- **必须在肾科医师或营养师指导下使用**
- 肾功能不全患者切忌擅自使用普通高蛋白ONS

**肿瘤专用（高热量高蛋白含EPA）**
- 专为肿瘤患者设计，含较高EPA抗炎成分
- 适用：肿瘤相关营养不良，需较高蛋白质摄入

根据美国言语-语言-听力协会（ASHA）临床指引，ONS的选择应结合患者的整体营养状况评估，由营养师和医疗团队共同决定（[ASHA Adult Dysphagia](https://www.asha.org/practice-portal/clinical-topics/adult-dysphagia/)）。

## 关键选购标准

### 1. 质地与吞咽安全

**这是吞咽障碍患者选择ONS时最重要的考量。**

对照国际吞咽障碍饮食标准（IDDSI）框架（[IDDSI Framework](https://www.iddsi.org/framework)），所有液体型ONS在未增稠前均为0-1级，不适合大多数吞咽障碍患者直接饮用。购买时需确认：

- 是否有配套增稠产品或已是预增稠配方
- 增稠后是否会影响营养成分（部分增稠剂会改变营养素的生物利用率）

### 2. 热量与蛋白质含量

根据患者的[营养不良筛查](/zh-cn/malnutrition-screening)结果选择合适密度：

| 患者情况 | 建议选择 |
|--------|---------|
| 轻度营养不良，仍能进食适量食物 | 100kcal/100ml通用型 |
| 严重营养不良，进食量极少 | 150-200kcal/100ml浓缩型 |
| 需要高蛋白质（肌少症、压疮愈合） | 蛋白质≥6g/100ml高蛋白型 |

### 3. 口味接受度

患者拒绝服用是ONS失败的最主要原因。建议：
- 初次使用时提供小份试饮，选择患者接受的口味
- 不同口味交替使用，避免味觉疲劳
- 稍微冷藏（非冰冻）可改善口感

### 4. 合并症禁忌

- 乳糖不耐受者：选择无乳糖配方
- 肾功能不全者：必须选择肾病专用型，避免高磷钾产品
- 糖尿病患者：选择低血糖指数配方，监测血糖变化

## 大陆养老机构的ONS管理规范

### 使用启动标准

建议养老机构制定清晰的ONS启动触发条件：

1. MNA-SF筛查得分≤7分（营养不良确诊）
2. 连续1周进食量低于目标量50%
3. 近1个月非预期体重下降≥5%
4. 营养师评估后开具处方

### 剂量与时间安排

- 通常作为**餐间补充**（而非代替正餐），避免影响正餐食欲
- 建议在餐后2小时或下午茶时段给予
- 每次量不超过200ml，避免过度饱腹影响下一餐

### 效果追踪

- 每月称重，评估体重趋势
- 记录ONS实际服用量（拒绝率是重要评估指标）
- 每3个月由营养师重新评估是否需要继续或调整方案

## 居家使用注意事项

家庭照护者购买ONS时，建议：

1. **咨询社区医生或营养师**再购买，避免选错配方
2. **检查有效期**：ONS一旦开封，需在规定时间内（通常24小时）用完
3. **储存条件**：未开封产品室温储存，开封后冷藏
4. **增稠处理**：必须严格按照言语治疗师处方的IDDSI等级进行增稠处理，不可擅自省略
