# IDDSI 第2级轻微稠化液体：临床适应症与居家配制指引

国际吞咽障碍饮食标准化倡议（IDDSI，International Dysphagia Diet Standardisation Initiative）框架将液体分为0–4级。**第2级轻微稠化（Mildly Thick）**是最常见的临床推荐级别之一，适用于需要轻微放慢液体流速以帮助咽期启动的患者。

理解第2级液体的精确标准和正确配制方法，是照护者和护理人员日常执行言语治疗师（ST）建议时的核心技能。

---

## 第2级液体是什么样的？

依据IDDSI官方定义，第2级轻微稠化液体的特征为：

- **外观**：比清水略稠，但仍是流动性液体，呈半透明状
- **流动行为**：从汤匙缓慢流下，在汤匙表面留下薄薄的涂层
- **口感**：喝到嘴里有轻微的"黏感"，但不感觉像糊状物
- **用途**：可用于饮水、调配茶、果汁、汤水等日常饮料

**与其他级别的直觉对比**：
- 第0级（稀薄液体）= 普通清水
- 第2级（轻微稠化）= 介于水和稀奶油之间，略似植物蜂蜜的稀版
- 第3级（中度稠化）= 类似稀薄的酸奶或淡炼奶

## IDDSI流速测试（10ml注射器测试）

IDDSI提供标准化的测试方法，确认液体稠度符合第2级：

### 10毫升注射器流速测试

**材料**：10毫升规格的注射器（去除针头）

**操作步骤**：
1. 将注射器直立，注入测试液体至10毫升刻度线
2. 用手指封住出口
3. 水平放置2分钟，使液体静置稳定
4. 将注射器垂直竖立，同时移开手指，计时10秒
5. 10秒后读取注射器内剩余液体量

**第2级判断标准**：
- 10秒后注射器内剩余**1–4毫升**（即6–9毫升已流出）
- 剩余>4毫升 = 液体偏稠（达到或超过第3级）
- 剩余&lt;1毫升 = 液体偏稀（接近第1级或第0级）

**实用提示**：建议每次配制新一批稠化液体时，或更换稠化剂品牌/批次时，执行一次流速测试，确认稠度符合要求。

## 第2级液体的临床适应症

言语治疗师会在以下情况下推荐第2级稠化液体：

### 咽期吞咽延迟（轻度）

咽期吞咽反射的启动时间延迟，意味着液体到达咽部后需要更多时间才能触发保护性咽反射。第2级液体流速比清水慢，可为患者提供稍多的反应时间，降低液体在反射尚未完全启动时就进入气道的风险。

### 轻度喉部关闭不全

喉部上抬或声带闭合轻度减弱时，稠化液体流速慢、黏性较高，相对不容易穿过声门间隙进入气道。

### 从更高稠度级别降级过渡

患者吞咽功能逐步恢复时，言语治疗师可能会从第3级或第4级逐渐降至第2级，第2级是向稀薄液体（第0级）过渡前的常见中间站。

**注意**：第2级液体的推荐须由ST根据仪器评估结果确定，照护者不应自行决定更换稠化级别。

## 居家配制方法

### 使用商业增稠剂

目前市面上主要有两类增稠剂（详见本站增稠剂选购指南）：

**黄原胶基增稠剂（推荐）**：
- 优点：温度稳定，调配后稠度不因温度变化而漂移，也不随时间持续增稠
- 缺点：部分人觉得口感略有滑腻感

**淀粉基增稠剂**：
- 优点：常见、价格较低
- 缺点：热饮中稠度不稳定（加热后会变稠），液体静置一段时间后可能继续增稠，需特别注意不要超过推荐稠度

### 配制步骤（以黄原胶基增稠剂为例）

1. 准备液体（水、茶、汤等），控制液体温度（根据增稠剂说明书，通常热饮需稍微降温）
2. 按照增稠剂说明书，取对应第2级的推荐用量（通常每100毫升液体约1–2克，但不同品牌差异较大，以说明书为准）
3. 将增稠剂粉末缓缓撒入液体，同时持续搅拌至少30秒，避免结块
4. 静置1–2分钟，待稠度稳定后使用
5. 使用前可做汤匙测试：将液体舀至汤匙后向下倾斜，液体应缓慢流下，在汤匙表面留下薄涂层

### 不同液体的配制注意事项

- **牛奶**：牛奶本身有轻微黏度，加入增稠剂达到第2级所需用量可能少于清水，需测试调整
- **热汤**：热液体会加速黄原胶溶解，但淀粉基增稠剂遇热会过度增稠，需注意
- **酸性饮料（果汁、酸奶饮品）**：黄原胶在强酸性环境中稳定性高，淀粉基增稠剂则可能降低稠度，须测试确认

## 常见错误与纠正

| 常见错误 | 正确做法 |
|---------|---------|
| 凭感觉估计增稠剂用量 | 每次使用量匙精确称量，并定期做流速测试 |
| 将增稠剂一次性倒入液体 | 缓慢撒入，同时搅拌，避免结块 |
| 液体冷却后未重新检查稠度 | 尤其使用淀粉基增稠剂时，冷却后重新测试稠度 |
| 自行决定改变稠化级别 | 任何级别变化须经ST重新评估后推荐 |
| 将稠化液体分多次配制、存储过久 | 建议每餐前新鲜配制，最多提前2小时；黄原胶基产品相对稳定 |

## 患者依从性的实际挑战

许多患者（尤其是轻度吞咽障碍患者）对稠化液体的口感感到不满，可能拒绝使用。照护者可采取以下策略提高依从性：

- 解释稠化液体的必要性（"这是为了防止水进入肺部"）
- 尝试不同增稠剂品牌，找到患者最能接受的口感
- 使用患者偏好的饮料（如茶、果汁）替代白开水进行稠化，增加接受度
- 若依从性极低，告知ST，由ST重新评估是否有其他代偿策略可以替代稠化
