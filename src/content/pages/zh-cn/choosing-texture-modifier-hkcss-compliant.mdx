# 从普通增稠剂到符合照护食标准：如何选择正确的质感调整剂

走进香港任何一间药房，架上至少可以看到两三种增稠产品。它们外观相似——白色或米白色粉末，以罐装或小包装出售——但在食物中和体内的表现截然不同。

选错增稠剂，不只是口感不对的问题。它可能意味着一份在厨房测试时达到处方 IDDSI 等级的膳食，在当事人口腔内已稀化至危险的浓稠度。对于任何旨在符合 **HKCSS 护食标准照护食认可计划**或维持 IDDSI 合规护理的厨房，选择正确的质感调整剂是一个临床决定，而非商品采购决定。

---

## 两大主要类别

香港用于吞咽困难护理的所有食品级增稠剂，均属以下两大类别之一：

1. **淀粉类增稠剂** — 通常为改性玉米淀粉或木薯淀粉
2. **黄原胶类增稠剂** — 一种用作水胶体的微生物多糖

---

## 淀粉类增稠剂

### 特性

| 特性 | 淀粉类表现 |
|------|----------|
| **温度稳定性** | 在热液体中增稠更多；在冷液体中持续增稠 |
| **时间稳定性** | 配制后黏度继续增加——若放置过久可能超出目标等级 |
| **外观** | 不透明，略带混浊 |
| **味道影响** | 剂量较高时有淀粉余味 |
| **唾液互动** | **关键限制：** 唾液中的淀粉酶分解淀粉——口腔内浓稠度显著降低 |
| **成本** | 每份成本通常较低 |

### 淀粉酶问题

当人喝一口淀粉增稠饮品时，唾液淀粉酶立即开始酵素分解淀粉。到食团进入咽部的关键时刻，浓稠度可能比在杯中量度时稀薄了整整一个 IDDSI 等级。这对于处方第 3 等级的中度吞咽困难人士，代表真实的误吸风险。

---

## 黄原胶类增稠剂

### 特性

| 特性 | 黄原胶表现 |
|------|----------|
| **温度稳定性** | 在热液体和冷液体中具有一致的黏度 |
| **时间稳定性** | 约 2–3 分钟后黏度稳定；之后不会显著继续增稠 |
| **外观** | 清澈至略微雾状；保留茶、水及清汤的外观 |
| **唾液互动** | 能抵抗唾液淀粉酶——在口腔相全程维持处方 IDDSI 等级 |
| **成本** | 每罐成本通常较高，但每份所需剂量较少 |

### 符合 HKCSS 护食标准

HKCSS 护食标准计划的技术文件与 IDDSI 方法论一致。IDDSI 参考文献指出，**黄原胶类增稠剂提供更可靠的浓稠度稳定性**——尤其是抵抗淀粉酶的特性。对于寻求 HKCSS 认可的厨房，使用黄原胶产品能提供更强的浓稠度测试可靠性。

---

## 实用选择标准

选择质感调整剂时，请按以下顺序评估：

1. **可靠地达到处方 IDDSI 等级** — 每批新到货时均应测试
2. **稀薄饮品增稠的淀粉酶稳定性** — 如用于增稠水、茶、汤至第 2–3 等级，优先选择黄原胶
3. **温度相容性** — 同时供应热饮和冷饮时，黄原胶表现更一致
4. **配制规程支援** — 产品应附有每个 IDDSI 等级清晰、剂量具体的配制说明
5. **标签及 IDDSI 一致性文件** — 供应商应能提供确认其产品已按 IDDSI 方法测试的文件
6. **规模化成本** — 以每份成本计算，而非每罐成本

---

## 总结：决策指南

| 使用情境 | 建议类型 | 原因 |
|---------|---------|------|
| 增稠稀薄饮品（第 2–3 等级） | 黄原胶 | 淀粉酶稳定性；一致的咽部黏度 |
| 增稠食物至第 4 等级糊状 | 两者均可，须测试 | 食物中淀粉酶问题较轻 |
| 同一环境提供热饮及冷饮 | 黄原胶 | 温度稳定性 |
| 寻求 HKCSS 认可的厨房 | 优先选择黄原胶 | 符合 IDDSI 可靠性文件要求 |
| 成本有限的居家护理 | 淀粉，须 SLP 指导 | 如 SLP 记录处方调整则可接受 |
