# 為什麼院舍需要IDDSI合規審核？

國際吞嚥飲食標準化倡議（IDDSI）框架自2019年在香港逐步推廣，已成為本港照護食質量管理的主要參考標準。然而，許多院舍在實際運作中存在落差：廚房製作的食物質感與IDDSI標準不符、員工未受過正式培訓、文件記錄不齊全，或商業採購食品未經正式核實。

定期的內部合規審核，不僅保障長者的進食安全，亦有助院舍在接受社會福利署或醫管局外部評核時展示專業水準。

---

## 10項自我審核清單

院舍管理層或護理主任可使用以下清單進行定期審核（建議每6個月一次）：

| 項目 | 審核內容 | 達標 / 待改善 |
|------|----------|---------------|
| 1 | 每位吞嚥困難居民均有SLT訂明的IDDSI飲食級別紀錄 | |
| 2 | 廚房員工能正確說出IDDSI L3至L6的主要特徵 | |
| 3 | 廚房備有叉壓測試、湯匙傾斜測試的操作指引（可張貼） | |
| 4 | 每週至少一次以標準方法抽查食物質感 | |
| 5 | 採購的商業照護食有IDDSI認證或獨立測試報告 | |
| 6 | 居民飲食級別變化有書面記錄及SLT確認 | |
| 7 | 員工年度IDDSI培訓出席率達80%或以上 | |
| 8 | 廚房有食物攪拌機、食物溫度計及標準量杯 | |
| 9 | 有書面應急程序處理進食嗆咳事件 | |
| 10 | 有固定渠道更新最新IDDSI指引資訊 | |

## 員工能力評估框架

IDDSI合規不是廚房的單一責任，而是跨部門的協作。建議按以下角色制定能力要求：

**護理員（Care Workers）**
- 能辨識IDDSI L3至L7的視覺特徵
- 知道何時需向護士或SLT匯報進食問題
- 能正確協助居民以安全姿勢進食

**廚師及廚房員工**
- 能操作叉壓及湯匙傾斜測試
- 了解不同烹調方法對食物質感的影響（炆、蒸、攪拌）
- 能閱讀並執行IDDSI飲食製作指引

**護士**
- 能評估居民進食安全初步指標
- 知道轉介SLT的指徵
- 能更新及維護居民飲食記錄

## 廚房設備基本清單

以下設備是院舍廚房實施IDDSI合規的基礎配備：

- **食物攪拌機（blender）**：高功率型號，可處理肉類及硬質食材
- **食物篩**：用於過濾攪拌後的食物，確保達到L4質感
- **電子磅**：精準控制食材及液體份量
- **食物溫度計**：確保食物在安全溫度下供應及測試
- **標準量杯及注射器（10ml）**：用於IDDSI流質測試
- **計時器**：用於注射器流量測試（10秒計時）

## 文件記錄要求

合規文件是應對外部審查的重要依據，建議保留以下記錄：

1. **居民個人飲食計劃**：包括SLT訂明的IDDSI級別、最後更新日期
2. **質感測試記錄**：每次廚房測試的日期、食物名稱、測試結果
3. **員工培訓記錄**：培訓日期、內容、出席員工名單
4. **嗆咳/進食事故記錄**：事件詳情、處理過程、跟進措施
5. **供應商資料**：採購商業照護食的IDDSI認證文件

## T/SATA 094-2025 與 IDDSI 的香港適用比較

**T/SATA 094-2025**是中國吞嚥障礙膳食（團體標準），其7個級別與IDDSI框架有所對應但並不完全一致。香港院舍目前以IDDSI為主要參考標準，惟面向大灣區供應或有內地居民的院舍，應了解兩套標準的差異：

| IDDSI 級別 | T/SATA 094-2025 對應 | 主要差異 |
|------------|----------------------|----------|
| L2 稀流質 | 2級 低稠 | 黏度範圍略有不同 |
| L4 切碎及濕軟 | 4級 碎食 | T/SATA對粒度有更具體規定 |
| L5 細碎及濕軟 | 5級 軟食 | 基本一致 |
| L7 正常 | 7級 普通 | 一致 |

## SeniorDeli 認證供應商申請途徑

**康樂齡 SeniorDeli** 為香港首家獲IDDSI認證的照護食生產商及供應商。院舍若希望採購符合IDDSI標準的商業照護食，可透過SeniorDeli官網聯絡，了解機構採購及認證供應商合作計劃，包括產品試用、員工培訓支援及IDDSI文件配套。
