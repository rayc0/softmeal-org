# IDDSI 流量測試完整指引：10 mL注射器測試的操作步驟與誤差控制

**IDDSI 流量測試（Flow Test）** 是驗證稠化液體稠度等級的全球標準化測試方法。無論是醫院廚房、安老院舍還是居家照護環境，正確執行流量測試是保障吞嚥障礙患者液體安全的核心品質控制手段。

## 流量測試的原理與用途

流量測試利用重力測量液體在標準時間內的流動量，以此客觀評估液體稠度。測試工具簡單（一支注射器和計時器），可在任何環境執行，無需實驗室設備。

根據 [IDDSI 官方框架](https://www.iddsi.org/framework)，流量測試適用於驗證 Level 0–4 的液體稠度：

| IDDSI 等級 | 名稱 | 10秒流出量 |
|-----------|------|-----------|
| Level 0 | 薄液（Thin） | ≥10 mL（注射器排空） |
| Level 1 | 輕度稠化（Slightly Thick） | ≥10 mL（接近排空但稍慢） |
| Level 2 | 輕度稠化（Mildly Thick） | 8–10 mL |
| Level 3 | 中度稠化（Moderately Thick） | 4–8 mL |
| Level 4 | 高度稠化（Extremely Thick） | 1–4 mL |

詳見 [IDDSI 框架最終版本（2020）](https://www.iddsi.org/Portals/0/Documents/IDDSI%20Framework%20Final%20Version2_2020.pdf)。

## 所需器材

**必備器材**
- **10 mL 無針頭注射器**：必須符合 ISO 7886-1 或等效標準，活塞和針管直徑有統一規格（此點至關重要——不同品牌注射器的孔徑可能有細微差異）
- **計時器**：精確至秒，建議使用手機秒錶
- **標準量杯或小碟**：接收流出的液體

**注意事項**
- 注射器必須清潔乾燥，無殘留物
- 建議使用新的一次性注射器，或經充分清洗晾乾的重用注射器
- 測試前確認注射器活塞滑動順暢，無阻力

## 標準操作步驟

### 步驟一：準備液體樣本
1. 按照正常程序配製增稠液體
2. 讓液體達到 **室溫（20–25°C）**——這是標準化測試的重要前提
3. 充分攪拌，確保增稠劑均勻分佈

### 步驟二：填充注射器
1. 將注射器活塞完全推至底部（0 mL 位置）
2. 將注射器開口朝下浸入液體中
3. 緩慢向上拉動活塞，吸取液體至 **10 mL 刻度**
4. 確保注射器內無明顯氣泡（如有氣泡，輕彈注射器排出）

### 步驟三：垂直持握
1. 將注射器垂直握持，開口朝下
2. 用**拇指完全封住開口**，防止液體流出
3. 確保注射器保持完全垂直（偏斜會影響結果）

### 步驟四：計時並鬆開
1. 計時器就緒
2. 同時完成兩個動作：**移開拇指 + 開始計時**
3. 保持注射器垂直靜止，勿搖晃
4. **精確在10秒時**停止，立即用拇指再次封住開口

### 步驟五：讀取結果
1. 讀取注射器內**剩餘液體的刻度**
2. **流出量 = 10 mL − 剩餘量**
3. 對照上表判斷等級

### 步驟六：重複測試
- 建議重複測試 **3次**
- 計算3次平均流出量
- 3次結果差異應在 **±0.5 mL** 以內；若差異較大，需查找原因（溫度不穩定、操作技巧問題等）

## 常見操作誤差及糾正

### 誤差一：液體溫度不標準
**問題**：熱液體（如剛配製的熱茶）黏度較低，流量偏大；冷液體黏度較高，流量偏小，導致測試結果不準確。

**糾正**：所有測試必須在液體達到室溫（20–25°C）後進行。如需測試冷藏保存的液體，取出後靜置至回溫再測試。

### 誤差二：注射器型號不符
**問題**：使用非標準10 mL注射器（如兒科用注射器、特殊用途注射器），孔徑不同導致結果偏差。

**糾正**：統一使用標準成人10 mL一次性注射器，定期確認注射器品牌規格一致。

### 誤差三：計時不準確
**問題**：鬆開拇指和開始計時的動作不同步，或視線轉換導致停止計時時間偏差。

**糾正**：由兩人配合——一人持注射器，另一人計時；或充分練習使兩個動作同步進行。

### 誤差四：注射器未保持垂直
**問題**：注射器傾斜會改變重力效應，影響流出量。

**糾正**：使用支架或手持練習，確保注射器與地面垂直。

### 誤差五：活塞阻力
**問題**：活塞與針管之間的摩擦力過大（乾燥或有殘留物），導致液體流出受阻，流量偏低。

**糾正**：確保注射器清潔，活塞滑動順暢。如使用重用注射器，測試前預先推拉活塞2–3次。

## 測試頻率建議

根據 IDDSI 及 [ASHA 的品質保證建議](https://www.asha.org/practice-portal/clinical-topics/adult-dysphagia/)：

| 場景 | 建議測試頻率 |
|------|------------|
| 新增稠劑品牌首次使用 | 每個稠度等級各測試3次，確認符合 |
| 日常配製（院舍廚房） | 每批次製備後至少測試1份 |
| 院舍品質監控 | 每週至少抽查1次 |
| 溫度或配方改變後 | 立即重新測試 |
| 患者出現嗆咳/異常 | 立即核查液體稠度 |

## 測試記錄建議

每次測試結果應記錄以下內容：

- 日期和時間
- 液體名稱和配方（增稠劑品牌、劑量）
- 液體溫度
- 3次測試結果及平均值
- 判斷等級
- 操作人員簽名

完整的品質管控記錄有助於識別系統性問題，並在事故發生時提供文件依據。院舍審計標準詳見[院舍吞嚥安全審計清單](/zh-hk/operations-audit-checklist-care-home)。

## 流量測試的局限性

流量測試是實用的快速檢測工具，但需注意以下局限：

1. **無法反映口腔感知**：測試結果不等於患者實際口腔感受到的稠度
2. **溫度敏感**：室溫測試結果可能與口腔溫度下的表現有差異
3. **唾液影響**：唾液中的澱粉酶可分解澱粉類增稠劑，使稠度隨時間降低
4. **操作者依賴**：需要充分培訓才能確保結果可靠

## 小結

IDDSI 流量測試是驗證稠化液體等級的標準化工具。關鍵成功要素包括：使用標準10 mL注射器、確保液體達到室溫、精確計時、重複測試取平均值，以及定期記錄結果。院舍和醫院應建立定期流量測試制度，將其納入日常品質管控流程。
