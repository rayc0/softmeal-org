## 為何需要增稠飲料

對吞嚥困難患者而言，稀薄液體（水、茶、果汁、湯水）在口腔及咽部吞嚥期的移動速度過快。在氣道完成保護動作之前，液體可能已流入喉頭及氣管，引致誤吸。為液體增稠可減慢食團速度，讓吞嚥反射有更多時間觸發，氣道有更多時間閉合。

在香港，估計約 15–20% 的長者院舍院友需要增稠飲料，並廣泛用於急症病房及中風、柏金遜症、認知障礙症等神經系統疾病的家居護理。

## IDDSI 液體等級 0–4：各級別說明

**IDDSI 框架**定義了五個液體稠度等級，均可以標準 10ml 針筒測試：

| 等級 | 名稱 | 流量測試（10ml 針筒，10 秒） | 常見例子 |
|------|------|--------------------------|---------|
| Level 0 | 稀薄 | >10ml 自由流出 | 水、茶、湯水 |
| Level 1 | 極微稠 | 1–10ml 留在針筒內 | 部分果汁 |
| Level 2 | 低度稠 | 以細流倒出；留有薄薄塗層 | 忌廉湯 |
| Level 3 | 中度稠 | 以小塊從湯匙滴落 | 蜜糖狀稠度 |
| Level 4 | 高度稠 | 無法從杯中飲用；需用湯匙進食 | 布甸狀稠度 |

香港院舍最常處方的等級為 **Level 2**（輕度吞嚥困難）及 **Level 3**（中度吞嚥困難）。Level 4 用於咽部控制嚴重受損的患者。

**必須嚴格遵從言語治療師處方的 IDDSI 液體等級。** 不可自行估計 — 處方為 Level 3 時使用 Level 2，會大幅提高誤吸風險。

## 澱粉型與黃原膠型增稠劑比較

香港臨床及家居護理中使用兩種主要增稠劑：

### 澱粉型增稠劑

**例子：** 粟粉、改性澱粉增稠劑（如雀巢 Resource ThickenUp 澱粉版）

| 特性 | 澱粉型 |
|------|-------|
| **外觀** | 不透明、糊狀、略帶顆粒感 |
| **熱飲** | 持續增稠，可能超出目標稠度 |
| **冷飲** | 增稠效果穩定 |
| **味道** | 可影響風味；高劑量時有澱粉殘留感 |
| **離水** | 液體會隨時間從凝膠分離（穩定性較低） |
| **唾液作用** | 唾液中的澱粉酶會分解澱粉 — 在口腔中稠度下降 |
| **成本** | 一般較低 |

**主要問題：** 由於唾液澱粉酶會降解澱粉，液體在口腔中的實際稠度比量度時更稀薄 — 澱粉型增稠劑在最關鍵的氣道保護時刻可能未能達到目標稠度。

### 黃原膠型增稠劑

**例子：** 雀巢 Resource ThickenUp Clear、SeniorDeli 透明增稠劑、Nutilis Clear

| 特性 | 黃原膠型 |
|------|---------|
| **外觀** | 清澈至半透明 — 不改變飲料外觀 |
| **熱飲** | 高溫下穩定 — 適用於熱茶、咖啡、熱湯 |
| **冷飲** | 增稠效果穩定；在冷氣泡飲料中亦穩定 |
| **味道** | 對風味影響極微；患者口味接受度更高 |
| **離水** | 極少 — 凝膠可穩定數小時 |
| **唾液作用** | 不被唾液澱粉酶降解 — 在口腔中稠度保持穩定 |
| **成本** | 每份成本較高；但所需劑量較少，部分抵銷差價 |

**臨床傾向：** 香港大多數言語治療師現建議使用黃原膠型增稠劑，因其稠度穩定性更高且對味道影響極小。不被唾液澱粉酶降解，使其在吞嚥時更可靠地達到處方 IDDSI 等級。

## 家居使用增稠劑的實用建議

1. **準確量度** — 使用包裝上的劑量表，不可目測估計。Level 3 偏差 0.5g 可令稠度降至 Level 2。
2. **增稠劑加入液體，而非液體加入增稠劑** — 邊攪拌邊將粉末倒入飲料，防止結塊。
3. **等待靜置時間** — 黃原膠型增稠劑通常在 30–60 秒內達到目標稠度；澱粉型可能需要 1–2 分鐘。每次測試前必須等待足夠靜置時間。
4. **每次進食前使用 IDDSI 針筒測試** 確認稠度 — 10ml 針筒價格低廉，大多數香港藥房均有售（向藥劑師索取餵食針筒）。
5. **乾粉應存放於密封容器**，置於陰涼乾燥處。不應存放於雪櫃 — 濕氣會導致結塊。
6. **增稠飲料不適合冷凍** — 每次新鮮製備；不應批量冷凍增稠液體。

## 常見問題

**問：可以使用超市買的粟粉（粟米澱粉）代替增稠劑嗎？**

答：不建議將超市粟粉用於臨床吞嚥困難管理。粟粉需要加熱才能發揮作用，在熱飲及冷飲中的增稠效果難以預測，且唾液澱粉酶會大幅降解其稠度。臨床級黃原膠型增稠劑提供更一致、可預測的效果。

**問：香港的綜援或長者券是否涵蓋增稠劑費用？**

答：增稠劑不在綜援食物援助範圍內。部分非政府機構計劃及醫院醫務社工可協助符合資格的患者獲取產品，請在出院前向醫院醫務社工查詢。

**問：家人拒絕飲用增稠液體，說味道不同，有甚麼方法？**

答：黃原膠型透明增稠劑對味道影響極微。可嘗試以 Level 1 或 2 為調味飲料（淡果汁、淡茶）增稠，而非只加入清水 — 有味道的飲料接受度普遍更高。同時確保按患者喜好的溫度提供飲料。
