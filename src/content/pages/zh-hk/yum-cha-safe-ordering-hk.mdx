# 飲茶與吞嚥困難：核心風險

飲茶是香港最受珍視的家庭傳統之一，週末與家人共聚的點心早午餐，是許多長者的精神支柱。然而，傳統點心的質感對吞嚥困難患者構成多重威脅：

- **黏韌外皮**（蝦餃、燒賣）：容易黏附口腔及咽喉，難以形成食團
- **雙重質地**（小籠包、叉燒包）：湯汁與固體並存，難以同步控制
- **圓形細小**（魚丸、鵪鶉蛋）：易整顆滑入氣管
- **稀薄液體**（茶水）：速度難以控制，是誤吸的主要成因之一

本指南根據 IDDSI 框架，為常見港式點心提供詳細的安全評估及改良建議。

> **重要提示：** 本指南為一般性參考。每位患者的吞嚥功能不同，IDDSI 等級應以言語治療師的個別評估為準，切勿自行更改飲食限制。

## 常見點心 IDDSI 安全等級完整表

### 高風險點心（不建議）

| 點心 | 主要風險 | 建議 |
|------|---------|------|
| 小籠包 / 湯包 | 雙重質地：湯汁 + 固體肉餡 | 不適合任何 IDDSI 等級患者 |
| 整條腸粉（帶醬） | 滑溜，難以控制；醬汁增加稠度不穩定 | 不建議直接食用（見下文改良方法） |
| 蝦餃 | 黏韌皮 + 整顆蝦仁（圓形） | Level 6 以上才考慮，需大幅改良 |
| 燒賣 | 黏韌皮 + 肉餡 | 去皮改良後可能達 Level 5 |
| 叉燒包 | 鬆軟麵包 + 固體叉燒（雙重質地） | 不建議；可嘗試分開處理 |
| 湯丸 | 黏韌糯米，整顆圓形 | 不適合任何 IDDSI 等級患者 |
| 雞腳 | 骨多，軟硬不一 | 不適合任何 IDDSI 等級患者 |
| 豬腸 | 韌，質地不均 | 不適合任何 IDDSI 等級患者 |
| 蟹黃包 / 灌湯包 | 大量湯汁 + 固體 | 不適合任何 IDDSI 等級患者 |
| 竹升麵 | 彈牙 Level 7，難以咀嚼 | 不適合大部分吞嚥困難患者 |

| 點心 | 原本風險 | 改良方法 | 改良後可達等級 |
|------|---------|---------|--------------|
| 腸粉（整條） | 滑溜，難控制 | 剪成約 1cm 小段 | Level 5 |

| 蘿蔔糕（蒸版） | 蒸版較軟 | 選蒸版，切小塊，通過叉子壓力測試 | Level 5–6 |

| 蝦米腸粉 | 蝦米碎粒（質地不一） | 去除蝦米，只取腸粉磨糊 | Level 4 |

## 蝦餃、腸粉、燒賣的詳細改良方法

### 蝦餃（Hargao）

蝦餃的主要風險來自兩個部分：外皮（黏韌，易黏喉）及整顆蝦仁（圓滑，易誤吸）。

**改良步驟（目標：Level 5）：**
1. 用筷子或叉子將外皮撕開並去除
2. 將蝦仁切碎至最大顆粒 ≤4mm（Level 5 標準）
3. 加入少量蝦湯或白粥保濕
4. 以叉子壓力測試確認質地

**Level 4 版本：** 去皮後將蝦仁連同少量湯汁用攪拌機打成均勻糊狀，過篩後確認無顆粒。

---

### 腸粉（Cheung Fun）

整條腸粉質地滑溜且長，是最難控制的點心之一。患者嘗試咬斷時，未咬斷的部分容易整條滑入咽部。

**改良步驟（目標：Level 5）：**
1. 要求廚房不加醬汁，或要求醬汁分開放置
2. 用小剪刀將腸粉剪成約 1cm 小段
3. 加入少量湯汁或白粥確保濕潤
4. 以叉子壓力測試確認

**Level 4 版本：** 將整件腸粉（去醬汁）用攪拌機加少量水磨成均勻糊狀，過細目篩確認無顆粒。

---

### 燒賣（Siu Mai）

燒賣的黏韌外皮是主要風險，去皮後充餡（豬肉、蝦）的處理相對容易。

**改良步驟（目標：Level 4–5）：**
1. 去除燒賣外皮（黃色薄麵皮）
2. 用叉子將充餡壓平，確認無整顆蝦仁
3. 若有蝦仁，切碎至 ≤4mm（Level 5）或磨成糊狀（Level 4）
4. 加入少量肉汁或粥底保濕

## 茶水處理詳細指引

飲茶的「茶」同樣是主要考慮。所有中國茶均為稀薄液體（IDDSI Level 0）。

| 茶類 | 特性 | 處理建議 |
|------|------|---------|
| 普洱 | 稀薄，棕色 | 加黃原膠基增稠劑 |
| 鐵觀音 | 稀薄，清香 | 加黃原膠基增稠劑 |
| 壽眉 / 白茶 | 稀薄 | 加黃原膠基增稠劑 |
| 菊花茶 | 稀薄，含花瓣（雙重質地） | 先過濾花瓣，再增稠 |
| 熱茶 | 高溫 | 必須使用黃原膠基（澱粉基在熱飲中不穩定） |
| 凍飲 | 帶冰 | 冰融化後稠度改變，不建議 |

**增稠劑份量：** 以 200ml 茶水為例，達到 Level 3（流質）通常需要約 3–4g 黃原膠基增稠劑；Level 4 需要約 5–6g。不同品牌份量不同，以產品說明書及針筒流量測試為準。

## 與餐廳溝通的策略

香港酒樓的服務員通常對吞嚥困難（Dysphagia）這個概念並不熟悉，建議使用他們更易理解的說法：

**實用溝通話術（廣東話）：**
- 「呢位老人家吞嚥有困難，食物要切碎或磨糊，唔可以食整粒野」
- 「茶水唔可以直接飲，要我哋自己加粉調稠」
- 「有冇得蒸版蘿蔔糕？唔要煎版」
- 「魚可唔可以去骨切碎先上？」

**攜帶 IDDSI 卡：** 若患者定期外出飲茶，可預先製作一張簡單的說明卡，列明患者的 IDDSI 等級及主要禁忌，讓服務員轉交廚師參考。

## 常見問題

**Q：吞嚥困難患者可以飲茶嗎？是否需要完全禁止？**

A：不需要完全禁止。關鍵是根據言語治療師評估的 IDDSI 等級，選擇合適的食物並進行適當改良。清粥（過濾固體後）、蒸魚及改良版蒸點心是較安全的選擇。茶水必須根據需要增稠。保留飲茶的社交參與感，對患者的心理健康同樣重要。

**Q：蘿蔔糕是否適合吞嚥困難患者？**

A：煎蘿蔔糕因外皮較硬不建議。蒸蘿蔔糕（未煎）質地較軟，切成小塊後可能適合部分 IDDSI Level 5–6 的患者，但需確保無硬邊，並通過叉子壓力測試。具體適合性應由言語治療師評估。

**Q：飲茶時如何處理茶水？**

A：普通中國茶（普洱、鐵觀音等）均為稀薄液體（IDDSI Level 0），需要增稠液體的患者必須加入增稠劑。建議使用黃原膠基增稠劑，因其在熱液體中穩定性優於澱粉基增稠劑。菊花茶需先過濾花瓣再增稠。

**Q：哪些點心對吞嚥困難患者最危險？**

A：最危險的點心包括小籠包（湯汁加固體的雙重質地）、整條腸粉（滑溜難控制）、湯丸（黏韌糯米圓形）及雞腳（骨多質地不一）。這些食物不建議任何 IDDSI 等級的吞嚥困難患者食用。
