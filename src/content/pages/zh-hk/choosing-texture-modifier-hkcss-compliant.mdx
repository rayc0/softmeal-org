# 從普通增稠劑到符合照護食標準：如何選擇正確的質感調整劑

走進香港任何一間藥房，架上至少可以看到兩三種增稠產品。走進一間備貨充足的安老院舍廚房，可能找到更多。它們外觀相似——白色或米白色粉末，以罐裝或小包裝出售——但在食物中和體內的表現截然不同。

選錯增稠劑，不只是口感不對的問題。它可能意味著一份在廚房測試時達到處方 IDDSI 等級的膳食，在當事人口腔內已稀化至危險的濃稠度；或飲品過度增稠，導致液體攝取不足及脫水風險。對於任何旨在符合 **HKCSS 護食標準照護食認可計劃**或維持 IDDSI 合規護理的廚房或護理安排，選擇正確的質感調整劑是一個臨床決定，而非商品採購決定。

---

## 兩大主要類別

香港用於吞嚥困難護理的所有食品級增稠劑，均屬以下兩大類別之一：

1. **澱粉類增稠劑** — 通常為改性玉米澱粉或木薯澱粉
2. **黃原膠類增稠劑** — 一種用作水膠體的微生物多醣

此外亦有**複合產品**，將黃原膠與其他水膠體（如角豆膠或甲基纖維素）混合以調整質感特性，但在香港市場較為少見。

---

## 澱粉類增稠劑

### 工作原理

澱粉顆粒吸收水分並膨脹，增加液體的黏度。增稠過程在混合後仍繼續——液體放置後持續增稠。

### 特性

| 特性 | 澱粉類表現 |
|------|----------|
| **溫度穩定性** | 在熱液體中增稠更多；在冷液體中持續增稠 |
| **時間穩定性** | 配製後黏度繼續增加——若放置過久可能超出目標等級 |
| **外觀** | 不透明，略帶混濁 |
| **味道影響** | 劑量較高時有澱粉餘味；可影響茶及清湯的風味 |
| **唾液互動** | **關鍵限制：** 唾液中的澱粉酶（一種酵素）分解澱粉——口腔內濃稠度顯著降低 |
| **析水性** | 液體可能隨時間從凝膠中分離，尤其冷藏時更為明顯 |
| **成本** | 每份成本通常較低 |

### 澱粉酶問題

唾液互動是澱粉類增稠劑最重要的臨床局限性。當人喝一口澱粉增稠飲品時，唾液澱粉酶立即開始酵素分解澱粉。到食團進入咽部的關鍵時刻——氣道保護最需要的那一刻——濃稠度可能比在杯中量度時稀薄了整整一個 IDDSI 等級。

這意味著在廚房測試為第 3 等級（中度濃稠）的澱粉增稠飲品，在吞嚥反射需要回應的咽部，可能表現得更像第 2 甚至第 1 等級。對於一位處方第 3 等級的中度吞嚥困難人士，這代表真實的誤吸風險。

支持這一憂慮的研究自 2000 年代中期起在多本同行評審期刊發表（Cichero 等，2013 年及其後的 IDDSI 相關文獻；讀者可在 iddsi.net 查閱 IDDSI 參考資料清單中的具體引用）。

### 仍可使用澱粉類增稠劑的情況

儘管有澱粉酶限制，澱粉類增稠劑因成本較低及更廣泛的供應渠道，在香港部分環境中仍在使用。在以下情況下可能在臨床上仍屬可接受：

- 處方等級具有足夠的安全邊際（例如，在知悉部分稀化的情況下處方第 3 等級——這需要明確的 SLP 決定及文件記錄）
- 產品用於食物（非飲品），澱粉酶效應的影響相對較輕
- 成本限制使黃原膠產品無法獲取，且沒有更好的替代方案

任何使用澱粉類增稠劑的情況，均應在當事人的飲食記錄中詳細說明，並在處方 SLP 知情的情況下進行。

## 黃原膠類增稠劑

### 工作原理

黃原膠形成穩定的凝膠網絡，其黏度不依賴溫度或酵素活性。凝膠具有剪切稀化特性（在吞嚥的機械力作用下暫時變稀），但能迅速恢復黏度，在咽部提供受控的流動。

### 特性

| 特性 | 黃原膠表現 |
|------|----------|
| **溫度穩定性** | 在熱液體和冷液體中具有一致的黏度 |
| **時間穩定性** | 約 2–3 分鐘後黏度穩定；之後不會顯著繼續增稠 |
| **外觀** | 清澈至略微霧狀；比澱粉透明——保留茶、水及清湯的外觀 |
| **味道影響** | 在臨床劑量下味道影響極低；適合對風味變化敏感的患者 |
| **唾液互動** | 能抵抗唾液澱粉酶——在口腔相全程維持處方 IDDSI 等級 |
| **析水性** | 極低——冷藏飲品穩定性良好 |
| **成本** | 每罐成本通常較高，但每份所需劑量較少 |

### 符合 HKCSS 護食標準

HKCSS 護食標準照護食認可計劃的技術文件與 IDDSI 方法論一致。IDDSI 本身的參考文獻及臨床指引文件指出，**黃原膠類增稠劑提供更可靠的濃稠度穩定性**——尤其是抵抗澱粉酶的特性。

對於尋求 HKCSS 認可的廚房，使用黃原膠產品能提供更強的濃稠度測試可靠性：在廚房量度的黏度，將更接近當事人吞嚥時在口腔內感受到的黏度。

**這並不意味著澱粉類產品在認可計劃下被完全排除**，但意味著如果使用澱粉類產品，文件記錄、測試規程及 SLP 處方調整必須更加謹慎地管理。

## 實用選擇標準

為安老院舍廚房或居家護理環境選擇質感調整劑時，請按以下順序評估這些因素：

### 1. 可靠地達到處方 IDDSI 等級

首要標準是產品能否可靠地達到並維持處方 IDDSI 等級。每批新到貨時均應測試——即使是同一品牌的相同產品，也可能存在批次差異。飲品使用針筒流量測試；食物增稠劑使用叉子壓力或湯匙傾斜測試。

### 2. 稀薄飲品增稠的澱粉酶穩定性

如果產品用於將稀薄飲品（水、茶、湯）增稠至第 2 或第 3 等級，**優先選擇黃原膠類產品**。澱粉酶降解風險在臨床上過於顯著，不應忽視。

對於飲品的第 4 等級（極度濃稠）增稠，食團在口腔相停留時間較長，澱粉酶效應稍不明顯——但黃原膠仍是 HKCSS 認可實務的首選。

### 3. 溫度相容性

如果廚房同時供應熱飲（早晨湯水）和冷飲（凍檸茶），黃原膠類產品在不同溫度範圍內的表現更為一致。澱粉類產品在高溫下可能表現不穩定。

### 4. 配製規程支援

增稠劑應附有每個 IDDSI 等級清晰、劑量具體的配製說明（例如「每 200ml 加 X 克達到第 2 等級；每 200ml 加 Y 克達到第 3 等級」）。如果製造商只提供模糊指引（「加至所需濃稠度」），這是質量信號——符合 IDDSI 的產品應按測試等級說明劑量。

### 5. 標籤及 IDDSI 一致性文件

出於 HKCSS 認可目的，增稠劑供應商應能提供確認其產品已按 IDDSI 方法測試的文件。部分製造商在包裝上印有 IDDSI 等級聲明；如有此聲明，應索取測試方法文件。

### 6. 規模化成本

以每份成本計算，而非每罐成本。黃原膠產品每 200ml 所需劑量較少，部分抵消了較高的單位成本。對於每天為 50–100 名居民提供多份增稠飲品的安老院舍，每份成本差異可能比每罐標價差異更小。

## 香港可購得的產品

以下產品類型可在香港護理和藥房渠道購得。這是參考清單，並非 softmeal.org 的背書——請直接向供應商核實當前供應狀況及 IDDSI 合規狀態：

**黃原膠類產品：**
- 雀巢 Resource ThickenUp Clear 系列產品（黃原膠型）
- Nutilis Clear（Nutricia）—— 黃原膠基底，已記錄 IDDSI 等級
- 可透過醫療營養供應商購得的其他黃原膠類產品

**澱粉類產品：**
- 雀巢 Resource ThickenUp（原澱粉配方）
- 藥房及超市渠道的各種改性澱粉產品

**當前定價及供應：** 請直接聯絡醫療營養供應商；SeniorDeli（seniordeli.com）為香港護理市場備有質感調整產品，可參閱其當前產品系列，了解香港可購得的 IDDSI 相容選項。

## 總結：決策指南

| 使用情境 | 建議類型 | 原因 |
|---------|---------|------|
| 增稠稀薄飲品（第 2–3 等級） | 黃原膠 | 澱粉酶穩定性；一致的咽部黏度 |
| 食物增稠至第 4 等級糊狀 | 兩者均可，須測試 | 食物中澱粉酶問題較輕 |
| 同一環境提供熱飲及冷飲 | 黃原膠 | 溫度穩定性 |
| 尋求 HKCSS 認可的廚房 | 優先選擇黃原膠 | 符合 IDDSI 可靠性文件要求 |
| 成本有限的居家護理 | 澱粉，須 SLP 指導 | 如 SLP 記錄處方調整則可接受 |
