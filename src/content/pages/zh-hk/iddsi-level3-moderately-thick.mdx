# IDDSI 第3級「中度稠化」液體：流速測試標準與臨床應用

**IDDSI（國際吞嚥飲食標準化倡議）第3級——中度稠化（Moderately Thick）** 是針對中度液體吸入風險患者最常處方的液體稠度等級。正確配製並驗證第3級稠化液體，是保障吞嚥障礙患者飲水安全的關鍵環節。

## 什麼是 IDDSI 第3級？

根據 [IDDSI 官方框架](https://www.iddsi.org/framework)，第3級液體的主要特徵為：

- **10秒注射器流量測試（Flow Test）**：使用無針頭10 mL注射器，10秒內流出液體量為 **4–8 mL**
- 流動性類似濃縮果汁或稀糖漿，倒入玻璃杯後緩慢流動
- 可清晰從湯匙流下，但比第2級（輕度稠化）明顯較慢
- 以杯飲用時需用力，使用吸管可能費力或不實際

第3級在 IDDSI 8個等級中屬於液體類別（Level 0-4），其上為第4級糊狀（Pureed），其下為第2級輕度稠化。詳見 [IDDSI 框架最終版本（2020）](https://www.iddsi.org/Portals/0/Documents/IDDSI%20Framework%20Final%20Version2_2020.pdf)。

## 適用患者群體

第3級中度稠化液體主要適用於以下情況：

**主要適應症**
- 存在中度液體誤吸風險的患者
- 咽喉期延遲（pharyngeal delay），但吞嚥代償機制尚存的患者
- 舌頭控制力輕至中度下降，無法有效管理薄液的患者

**常見診斷**
- 腦血管意外（中風）後的吞嚥障礙
- 帕金森氏症早至中期
- 頭頸部腫瘤治療後的暫時性吞嚥功能下降
- 部分神經退化性疾病患者

根據 [美國言語語言聽力協會（ASHA）](https://www.asha.org/practice-portal/clinical-topics/adult-dysphagia/) 的臨床指引，液體稠度的選擇必須基於言語治療師（SLP）評估，並結合儀器評估（如螢光透視吞嚥研究 VFSS）的結果。

## 流速測試操作標準

### 所需器材
- 標準10 mL無針頭注射器（ISO 規格，活塞口徑統一）
- 計時器（精確至秒）
- 待測液體樣本（應達到室溫 20–25°C）

### 操作步驟
1. 將注射器活塞推至底部（0 mL 刻度）
2. 將注射器垂直放置，拇指按住注射器口
3. 緩慢抽取待測液體至10 mL 刻度
4. 確保液體中無氣泡
5. 計時器就緒後，鬆開拇指，同時開始計時
6. 10秒後停止，讀取仍留在注射器內的液體量
7. **計算流出量** = 10 mL − 剩餘量

**第3級合格標準**：10秒流出量為 **4–8 mL**（即剩餘2–6 mL）

建議重複測試3次，取平均值。誤差應控制在 ±0.5 mL 以內。詳細流量測試指引參見[IDDSI 流量測試完整指引](/zh-hk/iddsi-flow-test-guide)。

## 常見配製誤差

### 1. 溫度控制不當
稠度對溫度高度敏感。熱湯加入增稠劑後冷卻，稠度可能從第3級升至第4級甚至更高。**必須在液體降至飲用溫度後重新測試**，確認稠度仍在目標範圍內。

### 2. 增稠劑種類不同，穩定性不同
- **澱粉類增稠劑**（如玉米澱粉、木薯粉）：在熱液中稠度更穩定，但長時間靜置後（尤其是加入唾液酶分解後）可能變稀
- **膠體類增稠劑**（如黃原膠、瓜爾豆膠）：溫度穩定性更好，稠度隨時間變化較小，但在酸性飲料中可能表現不同

### 3. 靜置後稠度變化
配製後放置30分鐘以上，部分增稠液體的稠度可能增加或降低，取決於增稠劑類型。**應在配製後盡快給患者飲用，如需提前配製，需在送達前重新測試**。

### 4. 非正式稠化方法的風險
香港和中國內地有使用**米湯（稀粥水）**作為非正式增稠方法的習慣。雖然米湯確實具有一定黏稠度，但其稠度因米水比例、烹煮時間不同而差異極大，**無法用流量測試穩定達到特定 IDDSI 等級**，不適合作為醫療目的的稠化方案。

## 增稠液體的保存建議

| 情況 | 建議 |
|------|------|
| 配製後立即使用 | 最佳選擇 |
| 冷藏保存 | 最多24小時，使用前重新測試稠度 |
| 加熱後再飲用 | 加熱後必須重新測試稠度 |
| 已飲用部分後剩餘 | 不建議保存，重新配製 |

## 患者教育要點

**照顧者和患者應了解的重點：**

1. **不可自行調整稠度**：不應因患者投訴味道不佳而自行減少增稠劑
2. **稠化不足的風險**：吸入稀薄液體可能引發吸入性肺炎
3. **脫水風險**：第3級液體口感較差，患者可能主動減少飲水，需定期追蹤液體攝取量（參見[追蹤液體攝取的實用方法](/zh-hk/caregiver-hydration-tracking)）
4. **等級調整需評估**：如患者進步或惡化，應請言語治療師重新評估，不應自行升降等級

## 第3級與相鄰等級的比較

| 特徵 | 第2級（輕度稠化） | 第3級（中度稠化） | 第4級（糊狀） |
|------|------------------|------------------|--------------|
| 流量測試10秒 | 8–10 mL | 4–8 mL | 1–4 mL |
| 視覺特徵 | 稍微稠於水 | 類似濃縮果汁 | 類似優酪乳 |
| 吸管飲用 | 可以 | 困難 | 不適合 |
| 杯飲 | 容易 | 需用力 | 非常困難 |

詳見[第2級輕度稠化液體完整介紹](/zh-hk/iddsi-level2-mildly-thick)，了解相鄰等級的差異。

## 小結

IDDSI 第3級中度稠化液體是中度吞嚥障礙患者的常見處方。準確配製和定期測試是保障安全的關鍵：使用標準10 mL注射器確認10秒流出量在4–8 mL範圍，注意溫度對稠度的影響，並向照顧者清晰說明稠度維護的重要性。任何稠度等級的調整必須由言語治療師評估確認。
