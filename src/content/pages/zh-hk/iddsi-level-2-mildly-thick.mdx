# IDDSI 第2級：輕度濃稠

**IDDSI 第2級——輕度濃稠（Mildly Thick）**是一種液體稠度，流速明顯慢於水和第1級，但仍可從杯中倒出。在舊版全國吞嚥困難飲食（NDD）分級中，此稠度稱為「花蜜稠（nectar-thick）」，香港臨床環境中仍沿用此說法，但IDDSI已採用中性術語，避免各國理解差異。

第2級液體在口腔中帶有輕微的包覆感——不像糖漿那樣厚重，但明顯比稀薄果汁有阻力。這種額外黏度能為咽部吞嚥反射爭取關鍵的時間裕量，降低輕度至中度咽部吞嚥困難患者的誤吸風險。

## IDDSI 注射器流量測試——第2級標準

標準IDDSI 10 ml注射器測試可區分第2級與相鄰等級：

| 等級 | 10秒後殘餘量 | 臨床描述 |
|------|-------------|---------|
| 0 | ≤1 ml | 稀薄 |
| 1 | 1–4 ml | 輕微濃稠 |
| **2** | **4–8 ml** | **輕度濃稠** |
| 3 | 8–10 ml（緩慢滴落） | 中度濃稠 |

**測試步驟：**
1. 用標準10 ml Luer滑入式注射器（不含針頭）抽取10 ml配製好的液體。
2. 垂直持握，針頭向下，用一根手指封住出口。
3. 同時啟動計時器並放開手指。
4. 恰好10秒後重新封住出口。
5. 對照注射器刻度讀取殘餘量。

**殘餘4–8 ml即確認為第2級。** 若低於4 ml，液體過稀（需增加增稠劑）；若超過8 ml，已超至第3級。

> **為何使用10 ml和10秒？** IDDSI研究委員會在國際多個實驗室和臨床場所驗證了此參數。使用不同規格的注射器或不同計時窗口會使結果無效。

## 哪些人需要第2級液體？

第2級通常推薦給稀薄液體存在誤吸風險，但能耐受流速較快的增稠飲品而不感疲勞的患者。常見臨床情況包括：

- **亞急性期中風**伴輕度咽部延遲——稀薄液體誤吸；第2級提供足夠過渡時間而不至於第3級的重量感
- **帕金遜病（早至中期）**——喉部上抬遲緩和環咽肌僵硬可受益於輕度增稠
- **輕度吞嚥障礙的認知症**——輕度增稠通常比中度增稠更易被接受，有助維持飲水量
- **老年衰弱**——咽部整體肌力減弱但咳嗽反射尚存；輕度增稠可減少夜間飲水時的隱性誤吸
- **頭頸癌（治療後）**——放射治療後數週內的咽部水腫和清除力下降

言語治療師（SLT）必須在進行正式吞嚥評估（如GUSS、MBSS或FEES）後，方可處方適當等級。

## 花蜜稠度與IDDSI第2級的比較

香港許多機構和家庭仍沿用NDD的「花蜜稠（nectar-thick）」說法。兩套系統大致相當，但並不完全相同：

| 參數 | NDD花蜜稠 | IDDSI第2級 |
|------|-----------|-----------|
| 定義測試 | 線擴散測試 | 注射器流量測試 |
| 黏度目標 | 51–350 cP | 約50–350 cP（重疊） |
| 國際標準化 | 否 | 是 |
| 食物名稱歧義 | 有 | 無 |

IDDSI第2級是現行國際標準。醫院管理局（HA）及香港職業治療師暨言語治療師學會已逐步採用IDDSI術語。仍使用「花蜜稠」的機構宜更新飲食卡和員工培訓至IDDSI語言。

## 香港常見飲品與第2級注意事項

| 飲品 | 備注 |
|------|------|
| 溫水 | 標準參考；先用此校準增稠劑用量 |
| 中國茶（菊花茶、普洱） | 略酸性；黃原膠增稠劑比澱粉類更穩定 |
| 豆漿 | 基礎黏度較高；可能需要較少增稠劑 |
| 甜湯 | 含糖量可影響澱粉類增稠速度 |
| 粥水 | 本身已由澱粉增稠；添加增稠劑前先測試 |
| 口服營養補充劑 | 確認廠商基礎黏度；部分產品已接近第1-2級 |

## 香港安老院舍（RCHE）執行要點

按社會福利署安老院舍實務守則，院舍須遵從醫療專業人員的飲食處方。IDDSI落實需要：

1. **言語治療師飲食卡系統**——記錄每位院友的現行IDDSI液體等級，每次重新評估後更新
2. **廚房員工培訓**——每年或每半年進行增稠劑配製和流量測試的實操培訓
3. **護理員培訓**——所有個人護理員了解哪些院友需要增稠液體及其等級
4. **探訪者溝通**——家屬必須知情；常見錯誤是家屬帶來未增稠的飲品（如維他奶、果汁）
5. **事故報告**——任何進食飲水期間的嗆咳、疑似誤吸均應記錄並觸發言語治療複查
