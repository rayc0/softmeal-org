# IDDSI 叉測試與滴流測試：固體食物等級驗證的操作指引

IDDSI 為不同質地的食物設計了多種現場快速測試方法。**叉測試（Fork Test）** 和**叉滴流測試（Fork Drip Test）** 是廚師和護理人員最常用的兩種工具，適合在廚房或病房快速驗證固體和半固體食物的質地等級。

## 叉測試（Fork Test）概述

叉測試主要用於驗證 **IDDSI Level 3–6** 的固體和半固體食物，通過觀察食物能否通過標準餐叉的齒縫，判斷食物粒徑是否符合要求。

根據 [IDDSI 官方框架](https://www.iddsi.org/framework)，標準餐叉叉齒間距約為4 mm，這一尺寸正好對應 IDDSI 固體食物的粒徑分界線。

### 所需器材
- 標準金屬餐叉（叉齒間距約4 mm）
- 待測食物樣本
- 良好光線環境（便於觀察）

## 叉測試的不同應用：各等級操作說明

### Level 4（糊狀 Pureed）——叉子壓平測試
1. 取一小份食物放在平面上
2. 用叉背輕壓食物
3. **合格標準**：食物應能被輕鬆壓扁，無法恢復形狀，不應有任何顆粒或塊狀物
4. **不合格**：有顆粒、有彈性、需用力才能壓扁

### Level 5（細碎濕潤 Minced & Moist）——叉齒通過測試
1. 嘗試將食物輕壓通過叉齒縫隙
2. **合格標準**：食物應能通過叉齒縫隙（粒徑 ≤4 mm），且食物濕潤有醬汁
3. **叉背壓碎測試**：叉背應能輕鬆壓碎食物顆粒
4. **不合格**：顆粒過大無法通過叉齒，或食物偏乾無醬汁

詳見 [IDDSI Level 5 細碎濕潤食物完整介紹](/zh-hk/iddsi-level5-minced-moist)。

### Level 6（軟質易咬 Soft & Bite-sized）——叉背壓力測試
1. 將食物放在硬平面上
2. 用叉背施以正常手指壓力（約 Newton 值等同用食指按鈴的力量）
3. **合格標準**：食物應能在此壓力下變形，但不完全崩散
4. **不合格**：需用力才能壓碎（過硬），或已完全糊狀（等級偏低）

詳見 [IDDSI 框架最終版本（2020）](https://www.iddsi.org/Portals/0/Documents/IDDSI%20Framework%20Final%20Version2_2020.pdf)。

## 叉滴流測試（Fork Drip Test）

叉滴流測試用於驗證 **IDDSI Level 4（高度稠化）液體或非常稀薄的糊狀食物**，通過觀察食物從叉尖的滴落方式，判斷其稠度是否符合 Level 4 的要求。

### 操作步驟
1. 用叉子舀取一份食物或稠化液體（約5–10 mL）
2. 將叉子提起，水平傾斜，觀察食物的滑落方式
3. **Level 4 合格標準**：
   - 食物從叉尖**緩慢滴落**，不是一整塊掉落
   - 滴落速度明顯慢於水
   - 在叉子上有輕微殘留

### 滴落方式的判斷
| 滴落表現 | 可能等級 | 判斷 |
|----------|----------|------|
| 快速連續滴落 | Level 2–3 | 稠度不足，不符合 Level 4 |
| 緩慢滴落，有拉絲 | Level 4 | 符合要求 |
| 整塊滑落不滴落 | Level 5–6 | 稠度過高，非液體類別 |
| 完全不滴落，靜止 | Level 6–7 | 固體質地 |

## 湯匙傾斜測試（Spoon Tilt Test）補充說明

叉測試通常配合**湯匙傾斜測試**使用，兩者互補：

- **叉測試**：主要驗證粒徑和硬度
- **湯匙傾斜測試**：主要驗證食物從容器滑落的方式（詳見[湯匙傾斜測試完整指引](/zh-hk/iddsi-spoon-tilt-test)）
- **流量測試**：用於液體稠度驗證（詳見[流量測試指引](/zh-hk/iddsi-flow-test-guide)）

## 廚房品質管控的應用

### 每班次製備後的測試流程

根據 [ASHA 的品質保證建議](https://www.asha.org/practice-portal/clinical-topics/adult-dysphagia/)，廚房應建立系統性的質地測試流程：

1. **每批次製備後測試一份樣本**（抽樣測試）
2. 對肉類、蔬菜、主食**分別測試**（不同食物可能達到不同等級）
3. 記錄測試結果（測試時間、食物名稱、結果、操作人員）
4. 如測試不合格，立即調整並重新測試，合格後才出餐

### 不同食物種類的測試重點

**肉類**
- 最常見問題：煮熟後偏乾，粒徑過大
- 建議：加入足夠汁液，測試前確認粒徑和濕潤度

**蔬菜**
- 最常見問題：煮熟後纖維未完全軟化，葉菜類難以均勻切碎
- 建議：延長烹煮時間，去除粗纖維部分

**主食（飯、麵）**
- 最常見問題：冷卻後變硬，或完全融合成糊狀
- 建議：加入湯汁保持濕潤，測試前確認溫度

**豆腐和蛋類**
- 通常天然符合 Level 4–5
- 注意蒸蛋不應有氣孔（過老），豆腐不應有硬皮

## 培訓廚師識別合格與不合格

廚師培訓中最關鍵的技能是識別「剛好通過」和「不合格」的視覺差異：

**有效培訓方法**
1. **照片對比**：準備合格和不合格食物的照片，讓廚師比較學習
2. **實物演示**：使用真實食物進行現場示範
3. **即時反饋**：培訓師在廚師測試時即時指正
4. **定期抽查**：由 SLP 或受訓主管定期驗核廚師的測試準確性

廚房整體質地管理流程詳見[院舍廚房質地改造工作流程](/zh-hk/operations-kitchen-workflow-texture)。

## 測試記錄格式建議

| 項目 | 記錄內容 |
|------|----------|
| 日期/時間 | 年月日，早/午/晚餐 |
| 食物名稱 | 具體菜式名稱 |
| 目標等級 | Level 4 / 5 / 6 |
| 測試方法 | 叉測試/叉滴流/湯匙傾斜 |
| 測試結果 | 合格/不合格 + 觀察描述 |
| 調整措施 | 如有，記錄調整內容 |
| 操作人員 | 廚師姓名 |

## 小結

叉測試和叉滴流測試是 IDDSI 廚房品質管控的核心工具，操作簡單、不需要特殊設備。關鍵在於：廚師熟悉每個等級的視覺標準，每批製備後系統性地測試，以及完整記錄結果。不同食物種類（肉類、蔬菜、主食）需分別測試，以確保每位住民獲得符合其處方等級的安全食物。
