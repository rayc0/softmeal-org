# 外出用餐與吞嚥困難

外出用餐是生活質素的重要組成部分。對於吞嚥困難（Dysphagia）患者及其照顧者而言，餐廳用餐充滿挑戰——菜單上的食物質感難以預判、廚房未必能配合特殊要求、嘈雜的環境令患者分心，增加誤吸風險。

然而，合理的準備和正確的點餐策略，可以讓患者在不完全放棄外出飲食樂趣的前提下，安全地享用合適的食物。

> **重要提示：** 本指南提供一般性建議。每位患者的 IDDSI 等級由言語治療師個別評估決定。外出用餐前，請確認患者目前的飲食限制，切勿自行調整。

## 香港主要餐廳類型的風險評估

### 茶餐廳（Cha Chaan Teng）

茶餐廳是香港最普遍的用餐場所，但其菜單對吞嚥困難患者挑戰較大。

**較適合的選擇：**
- 水蒸蛋（需確認無固體配料）
- 清湯麵（只取湯底，去除麵條及配料）
- 白粥或皮蛋瘦肉粥（過濾固體後取粥底）
- 燉蛋（質地接近 IDDSI Level 4）
- 牛油多士（Level 6，但需確認麵包已軟化，避免脆皮）

**需謹慎或避免的：**
- 通粉、即食麵（質地不一，難以控制）
- 西多士（外脆內軟，雙重質地）
- 混有固體的飲品（鴛鴦、奶茶泡沫）
- 三文治（麵包 + 固體配料，雙重質地）

### 中餐廳 / 酒樓

中餐廳提供較多可改良的食物選項，尤其是點心類和粥品。

**較適合的選擇：**
- 清粥或薄粥（過濾固體後）
- 蒸水蛋
- 蒸魚（去骨去皮，切碎至適合等級）
- 蒸豬肉餅（無筋絡）
- 芋頭糕或蘿蔔糕（蒸版，非煎版）

**需謹慎或避免的：**
- 蒸雞（骨多，皮黏韌）
- 整條帶殼蝦
- 燒味（酥脆外皮，雙重質地）
- 整碗湯麵（麵 + 湯 + 固體配料，混合質感）

### 酒店自助餐（Buffet）

自助餐的優點是可以自由選擇食物並即時處理，但需要照顧者主動把關。

**實用策略：**
- 只選取可確認質地的食物
- 利用自助餐熱台的保溫特性，選擇燉煮類軟質食物
- 自攜增稠劑，用以調整湯品或飲品的稠度
- 留意自助餐食物質地可能因補充批次不同而有所變化

## 向廚房提問的關鍵問題

在香港餐廳，主動與廚房溝通是保障安全的重要步驟。以下是建議詢問的問題：

| 問題 | 目的 |
|------|------|
| 這道菜是蒸的還是炸/煎的？ | 確認烹調方法（蒸版通常較軟） |
| 魚/肉可以去骨並切碎嗎？ | 確認廚房是否可處理 |
| 粥底可以只提供湯汁部分嗎？ | 確認可否去除固體配料 |
| 蛋可以蒸得較嫩滑嗎？ | 確認蒸蛋質地 |
| 這道菜有沒有小骨或軟骨？ | 排除骨頭風險 |

部分餐廳可能對特殊要求感到困惑或無法配合——遇到此情況，建議照顧者選擇最接近適合質地的菜式，回到座位後自行處理（如剪碎、壓平）。

## 隨身工具包

外出用餐時，建議攜帶以下物品：

### 必備
- **隨身增稠劑小包**（如黃原膠基增稠劑單次份量裝）
- **量匙或小磅**（準確量度增稠劑份量）
- **缺口杯**（讓患者飲水時無需後仰）
- **小剪刀**（剪碎食物用）

### 選帶
- **IDDSI 等級卡**（讓服務員或廚師理解要求）
- **10ml 針筒**（快速驗證飲品稠度）
- **濕紙巾**（清潔餐前口腔）

## 即場質感測試方法

在餐廳無法使用實驗室設備，但以下簡易方法可協助評估：

### 叉子壓力測試（固體食物）
取少量食物置於餐碟，用叉背施壓：
- **Level 4（糊狀）**：完全壓平，不回彈
- **Level 5（細碎濕潤）**：壓縮但仍可見顆粒
- **Level 6（軟質切小塊）**：可用叉側切開，有一定抵抗力

### 匙傾斜觀察（增稠飲品）
取一茶匙增稠後的飲品，傾斜湯匙：
- **Level 3**：慢慢流動
- **Level 4**：幾乎不流動，呈糊狀

## 高風險情境及應對

### 嘈雜環境
餐廳（尤其是中式酒樓或茶餐廳）通常十分嘈雜，患者容易分心，增加誤吸風險。

**應對方法：**
- 選擇偏僻或安靜的座位
- 進食期間請家人減少交談
- 提醒患者每口後停頓，確認已完全吞下才繼續

### 共享菜式
廣東飲食文化中，共享菜式是常態。其他家人可能無意間遞上不合適的食物。

**應對方法：**
- 出發前向同行人說明患者的飲食限制
- 患者的碗碟與其他家人分開，避免混淆
- 由一名指定照顧者負責所有食物的把關

### 季節性高風險食物
農曆新年（年糕、蘿蔔糕煎版）、中秋（月餅）、端午（糭）等節慶食物均屬高風險，應在外出飲食時特別提醒家人。

## 增稠劑在外的使用技巧

不同溫度的飲品對增稠劑效果有影響：

| 飲品類型 | 注意事項 |
|---------|---------|
| 熱茶（普洱、鐵觀音） | 使用黃原膠基增稠劑（耐高溫穩定）；澱粉基在熱飲中稠度不穩定 |
| 凍飲 | 加入增稠劑後需充分攪拌；低溫下增稠速度較慢，需等待 1–2 分鐘 |
| 含碳酸的飲品 | 不建議（碳酸本身對吞嚥困難患者已構成風險，增稠後泡沫亦難以控制） |
| 果汁 | 一般可增稠，但酸性果汁可能影響部分增稠劑的效果，建議預先在家測試 |

## 常見問題

**Q：患者應如何告知餐廳自己有吞嚥困難？**

A：最有效的方式是直接向服務員說明需要「軟質食物」並解釋具體要求（如「去骨並切碎」）。部分患者可隨身攜帶一張簡單的說明卡，列出可接受和不可接受的食物質地，方便溝通。

**Q：外出用餐時若患者突然嗆咳，應如何處理？**

A：立即停止進食，讓患者身體前傾，鼓勵自行咳嗽。若嗆咳可自行緩解，讓患者休息後再繼續（以較慢的節奏）。若出現持續咳嗽、聲音沙啞或呼吸困難，應立即就醫。

**Q：患者可以在餐廳飲用無增稠的水嗎？**

A：這完全取決於患者的言語治療師評估結果。若患者被評定為需要增稠液體（IDDSI Level 1–4），則任何稀薄液體（包括水）均需增稠。請攜帶自備增稠劑，切勿因為「在外不方便」而省略增稠步驟。

**Q：哪類香港餐廳對吞嚥困難患者最友善？**

A：一般而言，提供豐富粥品選擇的中式粥品專門店，或有蒸煮類食物的中餐廳，對吞嚥困難患者較為友善。避免以煎炸食物為主的快餐店，以及強調口感彈牙的日式餐廳（如壽司）。
